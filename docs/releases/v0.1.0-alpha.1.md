# Zipzi Editor 0.1.0 Alpha 1

First tagged Alpha build of the native macOS Editor. This is an early testing
release; APIs and project formats may change. Keep backups of your projects.

## Download

- `Zipzi-Editor-v0.1.0-alpha.1-macos-arm64.dmg`: recommended installer for Apple
  Silicon Macs. Open it, drag `Zipzi Editor.app` onto Applications, eject the disk
  image, then launch Zipzi Editor from Applications.
- `Zipzi-Editor-v0.1.0-alpha.1-macos-arm64.zip`: alternate app archive.
- `Zipzi-2D-v0.1.0-alpha.1-source.tar.gz`: corresponding workspace sources,
  vendored Editor patches, initialized Purism sources and license notices.
- `SHA256SUMS`: SHA-256 checksums of the DMG, app zip and source archive.

The DMG wraps the same signed App from this release's original tag build. Its
packaging script was added to the main branch after the Alpha tag; the App and
corresponding source archive retain the original release commit.

## Included

- Native modeling and animation workspace with WGPU/Metal rendering.
- Canvas editing, selection, parameter keyforms and timeline tools.
- Project import/export and an embedded host for the Python Runtime client.

## Alpha limitations

- The app is ad hoc signed, without Developer ID signing or Apple notarization.
  macOS may block the first launch. If you trust this build, use **System Settings
  → Privacy & Security → Open Anyway** after attempting to open it.
- This release builds and checks the bundle and source archive. It does not claim
  the complete Editor UI/native acceptance suite passed on a hosted GPU.
- This release provides an Apple Silicon build. Intel builds are not included.
- No proprietary Cubism SDK/Core binary or licensed sample models are included.
- Python wheels and Rust crates are not published to PyPI or crates.io in this
  release. The public Python distribution names are `zipzi` and `zipzi-native`.

SDK code is MIT; Editor code is GPL-3.0-only. The archives carry applicable
licenses, third-party notices and source provenance.
