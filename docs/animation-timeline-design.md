# Animation Timeline 设计

状态：2026-10-14 四个阶段均已实现，真实动作与 headless Metal 编辑／性能验收已执行。原生窗口合成帧率因测试机器锁屏未复测。Animation 工作区已使用可调整高度的总览／曲线 Timeline，具体证据与测量边界见下文及[验收报告](animation-timeline-validation.md)。

Timeline 编辑一个 MotionClip 的参数曲线和事件。核心工作流是选择通道、定位时间、修改数值、调整节奏和插值、验证播放效果。参数分组负责导航，关键帧总览负责节奏，曲线视图负责数值变化；三个视图使用同一份动画数据和选择状态。

## 范围与布局

第一版交付单 Motion 编辑，包括新建空动作、添加通道、关键帧增删改、批量移动与复制粘贴、曲线手柄、事件、事务预览、撤销重做以及保存重开。多 Motion 编排、音频轨道、持久化表情调度、物理烘焙不进入这一版。MotionGroup 继续表示资源注册分组。

Timeline 通过 `AnimationTimeline` 注册为 Animation 专属的 Dock Panel，默认位于底部。Dock 统一管理高度、折叠、关闭、拖动停靠、共享页签和最大化；Window 菜单与面板添加菜单提供显示入口。Timeline 不再保存独立高度或绘制自己的 resize handle。

布局位置、高度与显示状态保存在动画工作区布局中；首次加载旧版动画布局时重置为包含 Timeline 的默认布局，Modeling 布局版本保持不变。关闭、折叠或切换到其他页签时取消未完成的 Timeline 手势，候选配方与迟到回调仍按编辑身份隔离。

顶部保留紧凑的传输与编辑工具栏：当前 Motion、播放与定位、时间、总览／曲线模式、帧吸附、预览模式。时长、FPS、资源循环和淡入淡出放入动作属性，不长期占用工具栏。

左侧固定列显示层级、名称、紧凑可编辑数值和关键帧状态；右侧显示共用标尺下的关键帧或曲线。默认不为每行铺设滑块。选中通道时，检查区提供完整名称、范围、精确数值和滑块；选中关键帧时显示时间、值和相邻段插值。行内数值支持拖动调节和双击输入。

面板宽度小于 900px 时，通道列缩为 160px，检查区默认收起，通过工具栏按钮浮层打开；播放与工具入口合并为一行，动作选择、新建和其他时间轴工具收纳到菜单，预览模式与循环预览收纳到模式菜单。关键帧检查区不混入编辑头写值控件。时长、淡入淡出和缩放倍数按 0.01 单位／8px 拖动，FPS 按 1／8px，关键帧和事件时间按一帧／8px；Shift 进一步减小步长。模型范围内的通道数值保留按范围调节的拖动方式。

左右区域共用一份可见行布局和纵向滚动状态。切换总览／曲线保留时间范围与选区；曲线区默认只绘制选中通道，避免同时叠加数百条曲线。数值轴默认保持原始单位，多选时可主动开启归一化显示，归一化不改变数据。只在显式适配视图、切换通道时调整数值范围，拖动时坐标轴保持稳定。

分组使用缩进、展开状态和轻量分隔表达；选中项、播放头和曲线获得强调色。曲线颜色同时配合名称和选中描边，不依赖大面积分组底色。

## 数据边界

| 层 | 保存内容 | 生命周期 |
| --- | --- | --- |
| MotionClip | 轨道、关键点、曲线段、事件、时长、FPS、循环和淡入淡出 | 项目持久化，SDK 历史 |
| TimelineProjection | 参数分组树、通道关联、关键点索引、分组摘要、可编辑能力 | 派生缓存 |
| TimelineViewState | 展开、筛选、横向范围、滚动、显示模式、选区、吸附 | 按文档与 Clip 隔离的编辑器会话 |
| TimelineEdit | 一次操作的原始数据、候选数据、目标身份、候选版本 | 手势或命令事务 |
| AnimationSession | 预览配方、播放时钟、求值请求和呈现身份 | 文档预览会话 |

初版不把缩放、选区、展开状态写入动画资产，也不让视图变化产生文档脏状态。切换 Motion 保留其会话内视图，关闭文档清理对应状态。AnimationCatalog 继续服务资源列表和诊断；Timeline 从模型读取实际轨道，不能从资源摘要反推曲线。

## 行树与通道

参数行来自模型参数顺序、CDI 分组和归属，轨道通过 target 关联到参数。复用现有 parameter_groups、ParameterValue.group_id 及排序语义，将通用层级投影移入 editor-core，避免两个 UI 各自维护树构造规则。

默认显示已有动画的通道，保留祖先分组；空动作自动显示全部参数。筛选提供“已有动画”和“全部”，并支持名称与 runtime ID 搜索。搜索可发现尚未建轨的参数，临时展开命中路径；退出搜索恢复原来的展开状态。新增的轨道被选中并定位。筛选或折叠导致关键点不可见时，从可操作选区移除这些点，避免 Delete 操作隐藏内容。

不预先为所有参数创建空轨道。第一次写入关键帧才创建 MotionTrack。非参数通道单独组织为模型通道、部件不透明度和未解析通道；不伪装成模型参数。第一版可新建 Parameter、Model Opacity 和有效 PartOpacity 轨道。PartOpacity 是否能产生预期画面依据现有 Pose 诊断展示。

现有模型没有禁止同目标的多条轨道。导入数据原样保留：同目标多轨时展示轨道子行，编辑必须选择具体轨道，不自动合并；参数汇总行不提供含糊的写值入口。新建通道默认复用已有唯一轨道，有重复时要求选定其中一条。

折叠分组的摘要点由当前筛选范围内所有后代关键点生成，不包含事件。时间只在精确相同时合并为一个摘要；缩小时可以合并像素内的标记，但不合并数据。点击摘要选择其包含的关键点并展开、定位相应行；摘要本身不作为可拖拽实体，批量移动通过显式选区完成。

未解析目标、未知 Model 通道保留名称、原始曲线和诊断。第一版仅查看，不自动重绑。SDK 禁止编辑的未知扩展 Clip 整体只读，仍可查看和预览；不绕过 opaque 内容保护。

## 关键帧身份与曲线存储

为关键点增加持久 UUID，保留现有曲线段表达。初始点和段终点改用 MotionKey；Bezier 控制点继续使用无 ID 的 MotionPoint。结构示意如下，具体 Rust 命名在实现中统一：

```rust
struct MotionKey {
    id: String,
    time: f32,
    value: f32,
}

struct MotionTrack {
    id: String,
    target: MotionTrackTarget,
    initial: MotionKey,
    segments: Arc<Vec<MotionSegment>>,
    // 保留轨道淡入淡出和扩展字段。
}

// MotionSegment 保留四种插值；end: MotionKey。
// Bezier 的 control1、control2 仍为 MotionPoint。
```

不同时保存 keys 数组与 segments 数组。UI 的关键点序列是 initial 加各段 end 的投影。关键帧引用使用 clip_id、track_id、key_id；手柄引用使用所属段终点 key_id 和 Control1／Control2。索引仅用于局部遍历，不能成为跨操作的选择身份。

移动保留 ID，复制生成新 ID，撤销重做恢复原 ID，初始点与段终点相互转换时保留 ID。关键点 ID 参与项目校验和历史，但不写入 motion3 的曲线数字数组，也不作为未知字段内容指纹的一部分。导入分配 ID，重新导入视为资源替换，清理失效选区。项目尚未发布，不实现旧结构迁移。

SDK 新增按 ID 操作的关键帧及批量编辑接口。批量操作先构造完整候选 Clip，再校验、替换一次；不能逐点提交并要求每一步中间状态都合法。运行时 CompiledCurve 只需要时间、值和插值，身份不参与数值求值。

## 时间与碰撞

底层继续使用 f32 秒，界面换算和坐标计算使用 f64，写回时统一转为 f32 并校验。默认显示帧号，次要位置显示秒；支持切换为秒标尺。新动作默认 30 FPS、2 秒、非循环、显式零淡入淡出、无轨道和事件，名称自动避重。

帧吸附默认开启，用 Clip FPS 把操作目标换算为 n / fps。导入的非整数帧时间完整保留，不因显示、播放或打开而量化。拖动一组关键点时只吸附锚点，其他点使用相同时间偏移，保留内部节奏。关闭吸附可以编辑子帧时间。

同一轨道关键点时间必须严格递增。写值时优先使用明确选中的当前时间关键点，否则匹配写回后的精确 f32 时间；不按显示帧号或像素距离覆盖邻近点。鼠标命中必须返回具体 ID；重叠时放大或通过列表选定。

拖动不允许穿过未选中的相邻关键点，整体位移限制在合法区间。碰撞时不交换顺序、不自动合并、不覆盖其他点；粘贴与数值输入若发生碰撞，原子拒绝并标出冲突。若 f32 精度使目标无法区分，相应操作同样拒绝，不伪造最小间隔。

新建与移动内容限制在 [0, duration]。现有导入校验允许末端关键点略超 duration，显示范围必须包含这些点并标出名义结束位置；未编辑的尾点原样保留，选中编辑时可向合法区间内移动。修改 FPS 保留所有秒数，只改变刻度与吸附，并重新执行包括尾点容差在内的整段校验；不隐式缩放时间。若需要调整尾点，单独提供显式操作。

调整 duration 默认只改变边界；会使现有关键点或事件非法时拒绝。另设“缩放动画时间”命令，按同一比例变换所有关键点、Bezier 控制点时间和事件，再一起提交。不自动裁掉末端内容。

## 写值与关键帧操作

在 Timeline 修改数值，直接创建或更新当前时间的关键帧。初版不设置 Auto Key 开关，也不建立游离于曲线的待打帧值。拖动和数值输入期间使用候选数据，结束后写入一次历史，Escape 取消。这让每次编辑都有明确的时间和撤销边界。

播放时 Timeline 可编辑数值暂时只读；用户先暂停再编辑。按暂停时以已呈现画面的 SDK 局部时间定位编辑头并失效化在途帧，避免写到尚未看到的未来帧。无 Motion 时数值只读，显示创建或选择动作入口。只读结果监视继续承担观察最终参数的用途。

| 操作 | 确定行为 |
| --- | --- |
| 无轨道时写值 | 只在当前时间创建一个关键点；不额外生成 0 秒点。单点轨道按已有采样规则为常值 |
| 已有当前关键点时写值 | 更新该点，保留身份和相邻段类型 |
| 在段内写值 | 先按原曲线拆分并创建新点，再执行关键点改值与手柄跟随 |
| 插入关键帧命令 | 使用原始曲线采样值；无轨道使用模型默认值；不从最终 MotionSnapshot 取值 |
| 端点外插入 | 保留已有点，新连接段默认 Linear；无改值插入时使用相邻端点值，不隐式移动已有端点 |
| 删除中间点 | 合并相邻段；两个同类阶跃段保留该类型，两个 Bezier 段保留两端邻接手柄，其余组合连接为 Linear |
| 删除首点或末点 | 首点删除后把下一点提升为 initial 并移除连接段；末点删除后移除最后连接段 |
| 删除全部点 | 删除轨道，参数行仍可在“全部”中找到 |
| 总览拖动关键点 | 只改变时间，不跨行改变目标 |
| 曲线拖动关键点 | 改变时间和值；多曲线同时选择时允许共同移动时间，数值拖动只作用于单通道选区 |
| 复制粘贴 | 保留所选点的相对时间和值；锚点对齐播放头；连续选中区间保留内部段，外部连接段为 Linear |

删除不能承诺保持原曲线。合并 Bezier 时如手柄不满足时间约束，按新段边界缩短时间偏移，并保留合法值分量；结果参与实时候选预览。多个相邻点删除一次计算最终幸存邻点，不依赖删除顺序。

复制只针对选中的真实关键点；手柄随其保留的内部段复制。复制多个通道默认粘回同一 Clip 的原目标轨道；单通道复制允许粘到明确选中的兼容目标轨道。目标必须存在或是可建轨参数，类型、范围与时间统一校验；失败不产生部分写入。跨文档目标自动猜测和跨 Clip 粘贴暂不开放。

快捷键上／下一关键帧保留全动作导航范围，选中并展开目标关键帧所在通道；快捷键定位和检查区列表选择均保持缩放比例，将目标时间移入可见范围。逐帧定位只移动编辑头和必要的横向视野。

事件独立为一条标记行，按稳定 ID 编辑 time 和 value，同时间多个事件合法。列表投影可按时间排序，但不因显示排序改写存储顺序，同时间事件保持稳定次序。事件不触发外部副作用，也不把每次 seek 的 fired_events 累加为资产。

参数值输入和拖动限定在模型范围，Opacity 限定为 [0, 1]；导入的范围外值原样显示并可向范围内修正，不在打开时夹紧。Bezier 控制点允许值方向超调，最终预览是否夹紧由运行时负责。

## 插值与手柄

插值始终属于相邻关键点之间的段。检查区用“到下一关键帧的插值”表达，最后一点没有此属性；多选时只对具有下一点的所选点生效。保留 Linear、Bezier、Stepped、InverseStepped 四种类型，以小曲线示意表达两种阶跃的跳变方向。

新连接默认 Linear。显式切换为 Bezier 时，控制点初始化在连接直线的三分之一和三分之二处，不引入自动缓动。手柄默认独立，不提供未落入存储语义的自动平滑约束。

普通 Bezier 移动关键点时，邻接控制点跟随所属端点的时间和值位移，再将控制点时间约束到所在段内并保持控制点顺序；两端共同平移时整段完全平移。只改值时只平移对应控制点值。无需拖动手柄的编辑不自动改写其他段。

`restricted_beziers` 必须保持现有采样语义：true 时按端点时间线性计算 Bezier 参数，不使用控制点时间反解；false 时使用当前 SDK 的时间反解。因此 true 模式在图上使用有效的三分之一和三分之二时间位置显示手柄，水平手柄不可拖，只能调整值。写入涉及的受限段时规范化其控制点时间，不批量重写未编辑段。

插入未改值的 Bezier 关键点采用 De Casteljau 拆分。受限曲线使用线性时间比例；普通曲线必须复用 SDK 的时间反解分支。普通单调曲线要求拆分前后采样在数值容差内一致。非单调时间曲线若不能保证同一求值分支，保留读取、求值和端点数值编辑，禁用保形拆分与时间重排并说明原因；不偷偷改曲线。阶跃段保留原有边界求值规则，关键点存储值和边界瞬间采样值不保证相等。

## 编辑预览与结果预览

提供两个明确模式，默认“编辑预览”。编辑预览使用模型默认基线与当前 Clip 的原始通道值，不叠加 Motion 淡入淡出、Expression、Physics；保留 PartOpacity 所需的 Pose 求值。这样修改曲线时，参数运动容易理解。完整运行效果通过“结果预览”复用现有 Motion、Expression、Physics、Pose 和注册淡入淡出流程。

Timeline 行内数值始终代表编辑时间的原始通道采样；选中关键点时检查区另显示其存储值。原始值不受淡入淡出、参数夹紧、表情和物理反写。AnimationParameters 继续显示已呈现帧的最终值，并明确标为结果监视。

结果预览保留现有会话级表情触发记录，但不显示成可保存的表情轨道。纯 seek 不截断或重建这些记录；在过去激活表情仍按现有语义分叉。取消编辑恢复原有配方；提交曲线编辑保留有效记录并从新模型重新求值。切换 Clip 则建立新的预览运行。

资源 looping 与用户“循环预览”分开：前者写入 MotionClip，后者是会话设置。编辑预览可循环 [0, duration]；结果预览保留 SDK 的循环、淡入淡出和尾部采样语义。SDK 当前循环处理涉及 duration + 1 / fps，不能继续仅用 absolute_time % duration 推断阶段。由 SDK 返回局部采样时间、周期和当前循环编号供 Timeline 显示；循环接缝如落在名义边界外，以预览尾区显示，不伪造可编辑关键点。

用户定位或拖动时，实线编辑头立即移动到目标时间，画布保持最近有效帧直到新结果呈现；仅在明显落后时显示轻量计算状态。正常播放时主播放头跟随已呈现帧，不展示第二条持续竞争的时间线。结果预览在第 N 轮定位到局部时间时使用 SDK 的同轮时间映射，保留绝对时钟和表情记录；直接 seek 到 duration 不等同于自动进入下一轮。

每次曲线编辑开始时暂停并锁定编辑时间。播放、切换 Clip、文档或工作区会取消尚未结束的拖拽；数值框 Enter 或失焦提交有效输入，Escape 取消。菜单 Save 先结束有效编辑，Undo 在手势中先取消手势；取消不新增历史。候选失败保持最后合法候选并显示限制，不向 SDK 事务反复提交会中止事务的非法中间状态。

## 事务与异步身份

拖拽使用原始曲线加总位移计算候选，避免每次事件累积误差。轻量结构与曲线校验在候选层进行，完整 Clip 在提交前统一校验并进入 SDK 编辑事务。一次手势、粘贴或批量命令只产生一条历史，无变化不写历史。

候选动画需要独立快照输入。当前 animation_source 只读取已提交 AuthoringSnapshot，必须补充 SDK 的候选只读快照能力或等价的不可变候选源；不能为了预览临时提交模型，也不能借用 Modeling 参数预览覆盖冒充曲线修改。

求值身份包含文档、工作区、已提交模型版本、候选编辑 ID／版本、预览模式、预览配方版本、请求序号和视口版本。候选曲线每次变化都失效化相应编译曲线和 seek cache；合并未开始的请求，仅接收当前候选的结果。取消、提交、撤销、切换上下文都建立接受屏障，旧候选 CPU 或 GPU 结果不能重新覆盖画布。

SDK 事务负责资源变更和历史；editor-core 负责 Timeline 命令、选择与快照协调；GPUI 层负责坐标、命中、焦点和绘制。现有文档统一历史继续使用，不为 Timeline 建立第二套 Undo 栈。撤销重做后按 UUID 保留仍存在的选择，清理失效引用。

## 绘制与交互成本

行树和分组摘要按模型／Clip 版本缓存，不随播放每帧重建。纵向只布局可见行，横向通过有序时间索引查找可见关键点。网格、轨道和关键点静态层与播放头、选择框动态层分开失效化；播放不触发全量曲线重建。

画布平移、缩放和尺寸变化复用最近一次完成的动画姿态与共享几何，只更新视口渲染；视口结果返回时仅通知画布。姿态缓存校验文档、工作区版本、模型版本、预览版本、模式、候选身份、采样时间和完整播放配置，且保留请求序号、取消与 GPU 接受屏障。Motion、Expression、时间定位或关键帧编辑变化后重新求值，不复用旧姿态。

Animation Properties 按文档版本、Motion 注册、Expression 与语言缓存只读行数据；轨道、事件和元数据使用变高虚拟列表，仅构造可见行。画布尺寸测量只刷新画布与缩放状态，不通知整个编辑器。右侧 dock 的真实指针拖动纳入验收，对比 Modeling、Animation Info 与 Animation Properties，检查姿态和属性数据复用，以及 resize 后滚动至最后一行。

键盘命令只在 Timeline 或其检查区拥有焦点时处理，文本输入优先。左右键逐帧移动，独立命令跳到前后关键点，Delete 删除选中关键点或事件；通道与分组删除另设菜单，不能因行被选中就删除参数。空白拖动框选，标尺拖动定位，关键点拖动修改，三类命中区域不复用同一隐含手势。

## 实现顺序与验收

1. 在 kasane-2d 增加关键点 ID、按 ID 的批量曲线编辑和导入导出适配。覆盖 ID 保存、撤销恢复、四种插值、受限与普通 Bezier 拆分以及冲突原子性。
2. 在 editor-core 建立行树投影、Timeline 选择与命令、候选快照和两种预览模式。覆盖文档隔离、取消／提交／Undo 屏障、空轨道建帧、重复目标和能力诊断。
3. 用总览视图替换 PlaybackBar，接入事件、数值编辑、框选与批量移动，然后接入共用状态的曲线视图。首版完成前两种视图均需可用。
4. 用真实导入动作验证关键帧密集、子帧、末端容差、同目标多轨、未解析通道和未知扩展。测量滚动、拖动到呈现延迟、连续播放与快速 seek，防止退化。

验收必须包括：无操作保存不改曲线；一次拖动一次撤销；取消后资产与画面恢复；插入未改值关键点在支持的曲线上保形；跨轨批量移动冲突时无部分结果；重开项目恢复关键点身份；结果预览与现有 SDK 在相同配方和时间下保持一致。设计阶段不以未运行的测试作为完成证据。
