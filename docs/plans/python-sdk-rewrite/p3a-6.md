## 已修复的实际问题

- 统一读取的协议分支重复包裹成功响应，Connected 的 Snapshot 丢失顶层 Source；现在只封装一次。
- Job 启动调用名错误、Buffer 准备阶段同名覆盖、codec 私有化后的旧导入和传输方法参数不一致。
- 生成类型的运行时注解解析失败，包括公开模块重导出、ClassVar/Mapping/Version 和 bytes 字段遮蔽。
- 文档生成按未限定的 Create 等名称跨领域关联错误字段；改为按声明所属形状及生成文件/类匹配，并加入负控制。
- 资源便利方法参数此前硬编码，Rust 字段变更未传播；现在从编译声明生成，保留 PreparedImage 的手写所有权边界。
- 测试故障选择器更新到统一 read_selection 请求；新建文档明确属于未保存修改，40 次关闭使用显式丢弃，同时保留默认关闭拒绝断言。
- 2026-10-26 补齐字段语义：原 432 个公开路径的占位说明清零；177 个 Rust 导出声明的缺失字段说明写回所属声明，另补 59 个手写 Python 公开值字段。覆盖 ID/下标、坐标/单位、顺序、默认值/None、基础形态/增量和资源责任。
- 补齐图片创建参数展开、Plan 来源、事件载荷、泛型引用条目及 Python 关键字改名的文档映射。联合类型宏保留字段 Rustdoc；生成器对 Rust/手写 Python 字段缺文档直接报错，不再输出占位说明。
