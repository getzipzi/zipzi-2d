# Editor Glue 工具实施方案

状态：实现已落地，核心与格式回归通过，原生 UI 运行验收待完成。日期：2026-11-10。

本方案补齐 Editor 的 Glue 创作流程：在两个网格之间准备重叠顶点并绑定，通过四种权重笔刷调整接缝，使用参数控制整体生效强度，并完成解绑、删除、撤销和工程保存。底层已有 Glue 数据和求值能力，本次重点是补齐编辑操作及其一致性约束。

## 独立缝合工具（2026-11-10）

缝合与 Mesh Edit 的界面及操作状态分离。点击连接工具后依次选择两个部件；已有双选可直接点接缝。独立状态只接受点选，不允许拖动顶点，画布隐藏拓扑线及网格点。内部复用网格姿态映射和原子加点绑定事务。

完成后回到普通选择工具并选中接缝。属性面板提供贴合程度、跟随方式、编辑缝合点及高级权重笔刷入口。编辑已有接缝保持指定对象和 A/B 次序，移除模式点击端点删除配对而不删除网格点。空闲时 Esc 退出，按下期间 Esc 取消本次点击。Mesh Edit 工具栏和菜单均移除 Glue 控件。

以下为初版完整能力设计，默认交互以本节为准。

## 已确认的需求

1. 一次交付完整流程，包括绑定／解绑、A:B、A、B、重新吸附四种笔刷、可视化反馈、对象选择与删除、整体强度及参数编辑。
2. 创建方式参考 Cubism：在网格编辑模式准备重叠顶点，再执行绑定。补齐同时向两张网格添加重叠顶点；本次不提供任意两个不重叠顶点的直接绑定。
3. 主工具栏增加 Glue 入口，二级工具栏放笔刷模式与设置，属性面板放整体强度，画布提供可点击的 Glue 标签。
4. 每次笔刷拖动作为一个撤销步骤。保存和重开保留绑定、权重及强度；网格拓扑编辑继续保护被引用的端点。

以下数值、配对规则与采样算法是 Zipzi 的实施设计，并非 Cubism 内部算法的复刻。实现中可调整代码结构，但不得以底层字段已存在代替完整交互交付。

## Cubism 参照与术语

Cubism 在两个 ArtMesh 的重叠顶点间建立 Glue。顶点权重是静态的逐顶点配置，整体生效程度可逐关键形态设置并用于 BlendShape。绑定后的权重编辑与网格模式中的绑定／解绑是不同操作。[官方 Glue 手册](https://docs.live2d.com/en/cubism-editor-manual/glue/)

四种工具分别用于双侧比例、A 侧、B 侧和重新吸附。A:B 调整贴合位置，单侧工具允许顶点分开；重新吸附工具恢复贴合，Shift 可反向松开。笔刷提供强度、大小、硬度、圆／方／线形状、角度和颜色透明度。[官方工具详细面板](https://docs.live2d.com/en/cubism-editor-manual/detailed-toolpalatte/)

属性面板中的整体生效程度对应现有 `intensity`。界面统一称为“强度”，以区别笔刷的“笔刷强度”和每对顶点的权重；可通过参数关键形态控制。[官方属性面板](https://docs.live2d.com/en/cubism-editor-manual/inspector-palette/)

| 术语 | 本方案含义 |
| --- | --- |
| Glue 对象 | 连接固定两张不同网格，持有多组顶点对和整体强度 |
| 顶点对 | 由两侧稳定顶点 ID 引用的绑定关系，不合并网格拓扑 |
| A 和 B | Glue 创建时固定的两侧，分别以红、绿及文字标识 |
| 顶点权重 | 控制两端各自朝对侧移动的程度，不写入 Mesh 位置或关键形态 |
| 强度 | 整个 Glue 的生效程度，界面显示 0–100% |
| 解绑 | 删除顶点对；与把强度设为零、用笔刷松开顶点不同 |

## 创建与解绑流程

### 准备两张网格

选中两张可编辑网格进入 Mesh Edit，二级工具栏提供“同步加点”开关，默认关闭。开启后明确显示 A、B 网格名称；只有恰好两张目标网格时可用。常规点击切换当前网格的能力保留，同步加点不静默改变其他网格编辑操作的目标。

同步加点使用当前模型姿态中的同一位置，分别通过两张网格的姿态逆映射得到各自 UV，再复用已有形状重采样流程。两侧顶点使用独立的稳定 ID，保留各自三角形和固定边。任一侧逆映射不唯一、超出支持域或不可编辑时，整次操作拒绝并显示原因；不产生只有一侧的新点。同步加点仅在模型视图可用。

点击已有端点时复用唯一且足够接近的端点，可只向缺少端点的一侧补点；两侧均有端点时不创建重复点。命中多个候选时提示缩小范围，不根据数组顺序挑选。新增和复用的两个端点共同进入选择，便于随后绑定。

### 绑定

Mesh Edit 二级工具栏提供“绑定”和“解绑”。绑定时展示两侧名称及有效顶点对数量，以当前选择的两张网格为范围。

- 在当前求值姿态中匹配选中的重叠端点，依据模型坐标的数值容差；拾取半径不能直接作为绑定容差。容差统一定义，并用不同缩放级别的测试保证结果一致。
- 每个端点只能对应一个候选，选择中有未匹配、歧义或已被其他绑定占用的端点时整体拒绝，说明原因；不自动吸附相距较远的端点。
- 新建绑定默认每侧权重为 `0.5`、整体强度为 `1`。A/B 顺序在创建时固定，并在后续选择、保存和重开时保持。
- 显式指定目标 Glue 时追加顶点对，要求两张网格与其一致；没有指定时创建新的 Glue。允许同一张网格和同一对网格存在多个 Glue，以支持不同接缝的独立强度控制。
- 新建或追加的一批顶点对是一个原子操作、一个撤销步骤。再次绑定已经属于目标 Glue 的相同顶点对为无变化，不产生重复数据或空撤销记录。

Editor 新建关系限定每个顶点只参加一个顶点对，避免接缝重复约束。此限制作为 authoring 操作规则实施，不能通过修改全局加载校验而破坏已有导入模型。复杂导入关系的处理见“已有模型与异常状态”。

### 解绑和删除

解绑以目标 Glue 内所选端点涉及的完整顶点对为单位；选中一侧即可移除对应的整对关系，界面显示实际对数。操作不能移除未指定 Glue 中的关系。解绑只删除关系，不烘焙或修改网格形状，因此当前画面可能恢复为未粘合的姿态。

解绑最后一对后保留空 Glue 及其强度绑定，属性面板显示“无绑定顶点”；用户可以重新加对或删除整个对象。删除 Glue 走现有统一对象删除与依赖清理流程，不隐式删除两侧网格。

被绑定端点的删除仍需先解绑。保留稳定 ID 的内部网格生成继续保留 Glue，替换被引用顶点的边界／全量重建继续拒绝。移动端点遵循现有姿态逆映射约束，不能为 Glue 工具绕过拓扑保护。

## 权重笔刷语义

### 数据方向

现有求值中的 `weight_a` 表示 A 朝 B 移动的系数，而非“A 保持自身位置的优先级”。设该 Glue 应用前的位置为 `pA`、`pB`，强度为 `I`，则：

```text
qA = pA + I * weight_a * (pB - pA)
qB = pB + I * weight_b * (pA - pB)
```

在 `I = 1` 时，`weight_a + weight_b = 1` 表示两点贴合；两者都为 `0.5` 时贴合于中点。A 完全主导对应 `(0, 1)`，B 完全主导对应 `(1, 0)`。单侧降低移动系数会让该侧回到自身原位置，产生分离。

新建及常规笔刷输出保持 `0 ≤ weight_a`、`0 ≤ weight_b`、`weight_a + weight_b ≤ 1`。整体强度和权重独立，调整笔刷不得改变强度或把变化写入 Mesh 关键形态。

### 四种模式

下表是 Zipzi 的确定性行为基线。一次笔刷采样的有效量 `u` 由笔刷强度、硬度衰减和路径采样共同决定，范围为 `[0, 1]`；“趋向”采用按 `u` 的插值。

| 模式 | 普通拖动 | Shift 拖动 |
| --- | --- | --- |
| A:B | 双侧权重趋向 `(0, 1)`，加强 A 的主导作用 | 趋向 `(1, 0)`，加强 B 的主导作用 |
| A | 仅 `weight_a` 趋向 `0`，使 A 回到自身位置 | 仅 `weight_a` 趋向 `1 - weight_b`，恢复该侧贴合 |
| B | 仅 `weight_b` 趋向 `0`，使 B 回到自身位置 | 仅 `weight_b` 趋向 `1 - weight_a`，恢复该侧贴合 |
| 重新吸附 | 按当前双侧比例趋向和为 `1` 的权重；两侧全零时趋向 `(0.5, 0.5)` | 两侧同比例趋向零，逐渐松开 |

A:B 对已经贴合的顶点保持权重和为 `1`；作用于已经分离的顶点时逐渐恢复贴合并调整主导侧。单侧模式仅修改一项权重；重新吸附保留原有偏向，不一律重置为 50:50。强度小于 100% 时，即使权重和为 `1`，最终姿态仍可分离，这是整体强度的预期作用。

单侧模式的 Shift 行为及上述插值公式是 Zipzi 设计，官方手册并未定义对应的完整数值算法。

### 笔刷设置与采样

复用现有笔刷的形状、衰减与路径采样基础，Glue 独立保存工具设置，不覆盖选择笔刷的临时选择权重。基线默认值为圆形、直径 64 逻辑像素、笔刷强度 20%、硬度 50%、角度 0°、权重显示透明度 50%。大小范围复用现有 4–1024 逻辑像素；方形和线形支持角度，圆形禁用角度控件。

只绘制当前活动 Glue。单侧笔刷在该侧端点位置采样；A:B 和重新吸附要求两端都在笔刷范围内，使用两端较小的影响量，避免只擦过一侧便编辑范围外的端点。

一次拖动固定开始时的模型姿态、相机和顶点采样位置，以稳定 ID 计算累计权重变化。画面实时展示求值结果，采样位置不追随变形后的顶点，避免笔刷自反馈。路径按距离采样，保持相位连续，按下产生一次采样；静止不重复叠加。鼠标事件频率、屏幕刷新率不能决定笔刷强度。

Shift 可在拖动中即时改变方向，新采样采用新方向，不回溯重算此前轨迹。设置变化先结束当前手势。笔刷大小、角度、硬度的快捷交互接入已有输入路由；绑定／解绑快捷键先检查现有平台映射，避免覆盖现有命令。

## 界面与状态

### 入口与选择

主工具栏加入 Glue 图标和文字提示，菜单与工具栏共用命令状态。切换工具只改变编辑模式，不自动创建 Glue 或写入模型。无活动 Glue 时，二级工具栏说明如何在 Mesh Edit 创建绑定。

选中网格时显示关联 Glue 标签；Glue 模式下允许选择当前可见且处于隔离范围内的 Glue。点击标签或 Glue 对象行进入权重编辑，并同步属性面板。一个网格关联多个 Glue 时标签分开排列，显示对象名称；一次只有一个活动 Glue。

从 Mesh Edit 切换到权重工具时先按既有规则结束网格手势和模式。切回选择工具退出权重编辑。Delete／Backspace 在 Glue 对象选择上下文删除对象，在 Mesh Edit 中继续遵循点编辑语义，避免焦点导致误删整个 Glue。

### 工具栏与属性

二级工具栏按顺序展示：活动 Glue、A/B 网格名称、四种模式、笔刷强度、大小、硬度、形状及适用的角度；颜色透明度可放入设置弹出面板。窄窗口可折叠设置，但模式与活动对象始终可识别。

属性面板保留名称、运行时 ID、整体强度，补充只读两侧网格及顶点对数量。整体强度通过已有参数和关键形态编辑策略写入正确目标，明确区分基值、普通参数关键形态和 BlendShape 增量；不可编辑的参数位置显示原因，不能静默回写基值。

笔刷设置是 Editor 工具状态；Glue、顶点对、权重和强度绑定是正式模型数据。只调整笔刷设置、选择或显示透明度不产生模型撤销记录或工程脏标记。

### 可视化

- A 红、B 绿，并始终显示文字身份；颜色不能成为唯一的识别方式。
- 贴合端点显示合并标记，分离端点显示两侧标记和连接线。现有端点选择优先级与编辑权限规则保留。
- 权重颜色同时体现主导侧和吸附程度，不能只按 A:B 比例染色而把完全松开的顶点显示为贴合。
- 笔刷轮廓遵循实际形状、大小和角度；不可编辑对象显示禁用提示。
- 锁定的 Glue 显示灰色标签。Glue 或任一相关网格被锁定时，权重和关系编辑整体禁用；隐藏或隔离范围外对象不通过画布笔刷修改。
- 其他视口展示实时结果；只有手势所属视口接受该次绘制输入。切换文档、视口绑定失效、对象被外部删除时清理活动目标和悬停状态。

本次不新增全局 Glue 求值开关、完整复制粘贴关系闭包或压感输入。已有导入／导出能力需回归验证，不承诺复刻 Cubism 的所有外围管理功能。

## 事务与已有模型

所有正式修改通过现有 SDK authoring 和 Runtime 历史提交。一次双侧加点、批量绑定、解绑、删除或笔刷拖动各对应一个撤销步骤。笔刷使用 Draft 预览，抬起提交，Esc 取消；提交失败保留可恢复的所有权，按现有协议回滚或重试。无数值变化不写历史。

手势记录文档版本和稳定对象／顶点对 ID。外部 SDK 发布使捕获失效时停止使用旧候选，不能把旧权重覆盖到新拓扑上。保存、切换模式与退出应用遵循现有手势收尾规则，不能把未提交的预览误当正式保存结果。

已有模型正常权重和关系可以直接编辑。导入的重复端点约束、缺失端点、同网格关系或超出笔刷支持域的权重不在加载时自动修复。工具显示具体限制并阻止受影响的绘制或追加操作；保留检查、解绑与删除入口。不得只通过选择 Glue 就归一化权重、重排 Glue 求值顺序或改变模型画面。

## 实现分层与步骤

| 层 | 职责 |
| --- | --- |
| Contract 与 Core | 复用正式 Glue 数据，按需补命令契约；保证引用及数值校验，维持既有求值方向 |
| SDK | 双网格加点、绑定、解绑和权重批量修改的原子 authoring 语义；拓扑引用保护及失败回滚 |
| Runtime | 沿用正式事务、Draft、版本失效、历史和保存协调 |
| Editor Core | 模式、选择、配对、采样、权限、手势及叠加层投影 |
| Editor UI | 入口、二级工具栏、属性、标签、光标及中英日文反馈 |

### 第一步 固化模型与操作规则

确认已有通用 authoring 命令能覆盖哪些 Glue 写入，再补必要的专用操作。用双三角网格样例固定权重方向、部分吸附、解绑和多 Glue 行为。定义统一配对容差、端点唯一性检查和原子失败策略；新增契约时同步 Python 生成。

### 第二步 完成创建流程

实现双网格同步加点、成对选择、绑定／解绑和空 Glue 状态。与现有 Mesh Edit 的普通加点、移动、连接和生成共存，验证多形态重采样和端点保护。

### 第三步 完成权重编辑

实现四种模式和路径采样，接入 Draft 预览、撤销、Shift 切换及版本失效。保持每个顶点对只修改预期字段，先通过求值样例验证方向，再接入颜色反馈。

### 第四步 完成界面和参数流程

加入主／二级工具栏、标签、A/B 展示、锁定状态和属性信息。验证普通参数及 BlendShape 强度编辑、工具切换、多视口与键盘焦点。复用现有组件和光标体系。

### 第五步 完成持久化与验收

验证原生工程保存重开、现有格式路径中 Glue 的读写，以及完整用户操作。更新 Editor README，并把实际测试结果与剩余限制写入本方案。完成前保持状态为尚未实施或实施中。

## 验收标准

| 场景 | 通过条件 |
| --- | --- |
| 从零创建接缝 | 选两张网格、同步加点、绑定、退出 Mesh Edit 后可直接选择 Glue 并绘制 |
| 原子加点 | 任一侧映射失败时两侧均不变化，历史不新增；已有端点不会被重复创建 |
| 配对稳定 | 不同缩放、顶点存储顺序得到相同配对；非重叠、歧义、重复占用有明确反馈 |
| 默认贴合 | A/B 源位置为 0 和 10、强度 1、权重各 0.5 时两侧输出均为 5 |
| 主导方向 | 同一样例中 `(0, 1)` 输出均为 0，`(1, 0)` 输出均为 10 |
| 单侧分离 | 从 `(0.5, 0.5)` 将 A 权重降为 0 时 A 输出为 0、B 为 5，B 权重不变；B 模式对称 |
| 重新吸附 | 保留非对称比例恢复贴合；双零有确定回退；Shift 同比松开 |
| 整体强度 | 权重各 0.5、强度 0.5 时两侧输出为 2.5 和 7.5；强度零保留原姿态 |
| 参数驱动 | 普通参数和 BlendShape 均能改变强度；笔刷不改变其关键形态或网格位置数据 |
| 笔刷稳定 | 相同轨迹的密集和稀疏事件得到容差内一致结果；快速划过无漏点，静止不持续累积 |
| 历史与冲突 | 每次操作一个撤销步骤，Redo 重现结果，Esc 恢复；外部发布后不覆盖新数据 |
| 对象边界 | 多 Glue 只编辑活动对象；锁定、隐藏、隔离和空对象状态均有可验证反馈 |
| 拓扑保护 | 解绑前禁止删除引用端点，解绑后允许；内部生成保留关系；重建不产生悬空引用 |
| 持久化 | 保存重开后 A/B 身份、顶点对 ID、权重、强度及参数结果保持一致 |
| 界面完成度 | 主入口可发现，四模式及禁用原因可读，中英日文及窄窗口无关键操作缺失 |

## 实施记录

- 复用 SDK 的网格重采样和 Runtime Draft，新增以稳定顶点和顶点对 ID 为地址的 Glue authoring 操作。配对容差为 0.001 模型单位。
- Glue 工具默认快捷键为 `G`。按住快捷键拖动调整大小，配合 Shift 或 Alt 分别调整角度和硬度。
- BlendShape 关键形态的属性控件显示当前强度，写入时根据普通形态、其他 BlendShape 的贡献和目标权重换算增量。
- 新增 Glue 单元、双网格集成、Editor UI 和原生截图用例。原生截图入口为 `ZIPZI_SCREENSHOT_SCENE=glue`。
