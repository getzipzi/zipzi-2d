# Kasane 导入导出体验设计

状态：设计方案，尚未实现。核对日期：2026-10-18。

本方案覆盖 Kasane 编辑器的项目打开与保存、素材与模型导入、资源重新导入、运行时发布、可编辑项目交换、图片与动画成品输出。格式支持按方向和成熟度分别定义；没有通过相应验收的能力不得出现在产品的“已支持”列表中。

核心产品决策：一个统一的导入入口，一个按用途组织的导出窗口；保存始终保存 Kasane 项目。用户先选择要完成的工作，再看到对应格式及必要配置。转换损失、缺失依赖、输出范围和文件覆盖都在执行前可见。

| --- | --- | --- |

| 动画与附属数据 | SDK 有 motion、expression、physics、pose、CDI 导入导出 | 资源面板入口、ID 映射、冲突处理与文件写入 |

| Cubism 编辑项目 | SDK 可编码 CMO3、CAN3 及关联双文件；当前目标 schema 为 5.3 | 预检 UI、具体损失确认、发布入口；导入解析器尚未实现 |

| 图片、视频、音频与序列 | 编辑器已有 Metal 渲染和动画求值 | 离线帧管线、编码器、音轨、可复现采样、格式验收 |

以下配置均为目标设计，不能因为 SDK 有相似函数就视为 UI 已完成。项目尚未发布，格式与内部接口可直接重构，不设计旧版本迁移。

## 产品入口与共同规则

### 文件菜单

```text
新建项目…                 ⌘N
打开…                     ⌘O
打开最近项目              ▸
导入…                     ⇧⌘I
重新导入选中资源…
────────────────────────────
保存                      ⌘S
另存为…                   ⇧⌘S
导出…                     ⌘E
再次导出                  ⇧⌘E
导出任务…
```

快捷键作为默认建议，接入现有可重绑定 Command 系统；实现前检查与现有绑定冲突。导出预设也可从命令面板搜索。资源右键菜单提供“替换源文件”“重新导入”“导出此资源”；Timeline 提供“导出当前动画”。这些入口只预选统一窗口的内容，不维护独立转换逻辑。

“打开”遇到外部格式时路由到导入预检；完成后得到新的、未保存的 Kasane 文档。“导入”遇到 Kasane 项目时默认打开独立标签。“合并到当前项目”为 C 能力，需要对象身份、参数及资源引用的成组映射；A/B 不显示这个尚未实现的选项。保存不会回写 PSD、MOC3 或 Cubism 源文件。

### 拖放与识别

| 落点或输入 | 默认行为 |
| --- | --- |
| 欢迎页或标题栏 | 项目直接打开；模型、PSD 进入新项目导入 |
| 建模视图或资源列表 | 图像/PSD 预选“添加到当前项目”；模型文件预选“新项目” |
| 已选纹理资源 | 显示“替换此纹理”与“新增素材”，默认新增 |
| Timeline 或动画资源列表 | motion、expression、音频进入当前项目资源导入 |
| 文件夹或 ZIP | 扫描入口文件并展示候选项目；一个 model3 加其依赖算一个模型 |
| 多种文件混选 | 按模型依赖、图像、动画、音频分组；列出无法识别项，可移除后继续 |

优先识别文件头、JSON schema 和目录清单，再参考扩展名。`.motion3.json` 等使用最长后缀匹配，不把任意 `.json` 当模型。目录中多个 model3 必须选择，不把贴图再次作为独立图像导入。多模型默认分别新建标签；最多并行两个解码任务，其余排队。

### 窗口结构

导入使用标题为“导入到 新项目 / 当前项目名”的可调整大小窗口，三个阶段为“选择文件 → 检查与配置 → 导入结果”。简单图片可在检查页一次确认，不强制经过空白步骤。标准布局约 880 × 640 逻辑像素：左侧文件/图层列表，中间预览，右侧上下文配置；窄窗口合并为预览与配置上下排列。原生文件选择器只承担选路径。

导出窗口约 960 × 680：左侧用途分类，中间预览或输出文件树，右侧格式与配置，底部始终显示目标、预检摘要和主按钮。分类为“运行时模型 / 可编辑项目 / 动画与设置 / 图片 / 动画成品 / 项目打包”。基本配置默认展开，高级配置按格式出现；没有可调参数的格式不显示空配置区。

统一状态：空 → 扫描 → 需处理 / 可执行 → 处理中 → 成功 / 成功但有提醒 / 失败 / 已取消。扫描阶段可取消。仅发现无法可靠转换的具体内容时要求处理，不对正常操作重复确认。

## 格式支持总表

实施层级：**A** 为首批完整体验，主要接通已有能力；**B** 为补齐创作和交付流程，需要新增管线；**C** 为长期扩展，需独立实现与验证。这里的 A/B/C 是研发范围，不是当前产品的可用标记。产品 UI 只展示当前构建真实可用的方向，设置中的“格式支持”页可查看暂不支持的原因。

## 导入的具体配置

### 通用导入检查

选择文件后展示源格式/版本、大小、像素尺寸或模型资源数、导入目标、预计资源占用与问题数。仅有大文件尺寸不能推断解码内存安全；扫描时估算累计像素和解压体积，在分配前执行预算检查，超限可移除图层或拆分导入。

| 配置 | 默认与行为 |
| --- | --- |
| 导入方式 | 模型/整份 PSD 默认为新项目；资源面板入口默认为添加 |
| 目标位置 | 当前选中 Part；无选中时根级。只对追加图像/图层显示 |
| 资源存储 | 复制进项目；未保存文档由会话持有。源路径只用于重新导入 |
| 重名 | 新资源自动加显示名后缀；不同对象仍拥有独立内部 ID |
| runtime ID 冲突 | 预览映射表；禁止仅凭同名直接覆盖；成组重映射所有引用 |
| 失败策略 | 一个模型及其依赖为一个事务；独立批量项目可各自成功/失败 |
| 未识别扩展数据 | 能保留的附属数据原样保留并标记；不支持的语义列为问题 |

原文件只读。取消不产生半个文档；追加失败不改变文档和历史；成功追加/替换是一个可撤销命令。新项目导入只在全部必要资源准备好后创建标签。

### Kasane 项目

普通打开不弹配置。发现缺失或哈希不符资源才进入修复页，支持“选择资源文件夹”“逐项定位”“只读检查”。哈希不符资源必须列出变化；不能静默接受。检查模式可以展示缺失纹理占位，但不能发布需要该纹理的模型。

ZIP 必须识别唯一项目入口并检查路径安全；多个入口让用户选一个或全部打开。用户选择解包位置，默认新建同名工作目录；不在 ZIP 内直接编辑，不覆盖同名现有项目。分享包默认包含所有文档引用资源和未来编辑所需原图，排除缓存、临时文件、绝对路径和撤销历史。

### Live2D model3 与裸 MOC3

model3 检查页以依赖树显示模型、纹理槽、动作组、表情、物理、姿态、CDI、UserData 和声音。MOC3 与所有使用到的纹理为必需；可选文件缺失可明确“跳过并记录缺失”，与损坏的模型区分。默认导入全部已引用资源；取消动作/声音勾选时同步清理对应导入清单引用，不能生成指向未导入资源的假成功。

裸 MOC3 展示 `纹理槽 0 → 文件` 的表格，先扫描同目录候选，以尺寸与文件名提供建议，用户可替换。没有确定映射不能执行。支持“改用 model3 文件”以自动补全；不会宣称从 MOC3 恢复原始图层、作者命名或未嵌入动画。

版本显示来自解析器检测。当前 inspector 识别 3.0、3.3、4.0、4.2、5.0、5.3 标记，识别标记不等于全部特性可转换；实际导入以 decoder 和文档结构校验为准。未知版本阻止转换，给出检测值与支持范围，不猜测布局。

### PSD 与图像

| 配置 | PSD 默认 | 单图默认与约束 |
| --- | --- | --- |
| 导入内容 | 所有图层，包括隐藏层 | 当前图像；动画图必须选帧或序列模式 |
| 分组 | 保留目录层级为 Part | 多文件可建立同名素材分组 |
| 隐藏状态 | 保留为模型状态 | 新增显示 |
| 网格 | 矩形初始网格 | 矩形；“按透明轮廓生成”调用已有网格生成设置 |
| 坐标 | 保留源位置与像素尺度；追加可整体偏移 | 拖放点/模型原点；1 源像素对应 1 模型像素 |
| 透明裁边 | 开启，保留原尺寸与偏移元数据 | 默认开启；参考图保持完整矩形 |
| 颜色 | 目标为 sRGB，保留透明 | EXIF 方向先归一化；ICC 转换需颜色管理实现 |
| 素材用途 | ArtMesh | ArtMesh / 参考图 / 仅纹理 |
| 图像缩放 | 100%，不自动降采样 | 100%；预计过大时建议尺寸，不静默改像素 |

首批 PSD 必须如实显示当前子集：8 位 RGB、PSD v1，文件不超过 512 MiB、画布不超过 6400 万像素、单边不超过 30000、栅格层不超过 8192。当前累计解码像素超过 512 MiB 仅警告且继续；新预检需补充可取消、可控内存预算，不能把现有警告当硬限制。

普通、正片叠底、线性减淡以及已支持的剪贴结构可保留。图层蒙版、矢量蒙版、调整层、图层效果、某些分组透明度和不支持的混合结构目前会报错；文字/矢量/置入对象有有效栅格像素时可转图片并提示。检查页逐层定位问题，提供“返回源软件栅格化”或显式排除该层。只有实现了正确合成器以后，才提供“烘焙该组外观”；不能用 PSD 合成预览替代局部图层而声称保留分层。

ICC 色彩转换、图层筛选与自动网格是新增能力；未实现时仅展示已核验信息，不显示虚假开关。自动网格失败不必否定已成功解析的 PSD：用户可退回矩形网格。

### 重新导入与替换

资源记录来源文件指纹、逻辑图层身份、分组路径、尺寸与裁切偏移。现有 PSD ID 与文件指纹有关，源文件变化后不能靠现有生成 ID 做稳定匹配；新增来源表优先用源图层稳定 ID，退化到路径/名称/尺寸建议，歧义必须人工匹配。

差异页分为“已匹配 / 新增 / 消失 / 需确认”。默认只替换匹配图层像素，保留网格、变形器、参数绑定、显示名和模型位置；新增层默认新增，消失层默认保留并标记。尺寸或裁切变化显示对齐叠图，用户选“保留源像素坐标”或“缩放至现有区域”。纹理图集重新排版不能按整图缩放处理：没有区域映射就阻止替换受影响 UV。

整模型重新导入只提供“作为新项目比较”；A/B 不承诺自动合并外部 rig 修改。应用资源差异是一笔事务，撤销能恢复旧像素及映射。新导入资源的撤销也必须恢复来源表。

### 动画与设置文件

| 格式 | 配置及默认行为 |
| --- | --- |
| motion3 | 新建动作；名称取文件名，保留持续时间/FPS/loop/fade/曲线和事件；保留原始秒时间，不按当前时间轴 FPS 量化；可选择动作组 |
| exp3 | 新建表情；保留 Add/Multiply/Overwrite 和 fade；预览“应用前/后”；不改变模型默认值 |
| physics3 | 整套替换，显示输入/输出参数映射和差异；已有设置时保留取消入口；不默认合并物理链 |
| pose3 | 整套替换；核验 Part ID、关联关系及淡入设置 |
| cdi3 | 按 runtime ID 合并名称/显示分组；冲突默认保留当前值，可逐项采用源值；无匹配项保留诊断，不自动建对象 |
| userdata3 | 保存原始附件、更新清单引用；解析或目标校验不可用时标注“附件，未验证对象关联” |
| 音频 | 新建参考轨；起点为播放头、增益 0 dB、不循环、不自动驱动口型；绑定动作声音为独立选项 |
| CMO3/CAN3，未来 | 显示源版本、关联资源、模型对应关系和不可表示的编辑数据；CAN3 自动找同目录模型，找不到则定位 |
| CSV，未来 | 选择“参数定义/采样曲线”，编码 UTF-8，显式列映射；秒或帧必须选定，帧模式必须提供 FPS |

映射按 runtime ID 精确匹配优先，名称匹配只是建议。显示源 ID、目标 ID、源/目标范围和冲突；不默认缩放或夹紧数值。找不到参数时可手动映射、显式跳过相关轨道，或创建无绑定参数（需填写范围与默认值）；绝不伪造网格绑定。同名动作默认新增副本。替换已有动作需用户指定目标，保留其资源身份并更新引用。

“插入当前动作到播放头”属于 B：显示时间偏移、重叠区间和替换/保留规则，默认新建独立动作，避免把导入误当粘贴。

## 导出的共同配置与行为

### 内容快照

导出以当前已提交内容的不可变快照执行，不要求先保存。进入窗口前提交合法文本字段和 Timeline 候选，取消未完成建模手势，复用现有编辑生命周期规则；校验失败聚焦原字段。标题显示来源文档及快照时间。排队后继续编辑不会改变任务内容，完成提示“已导出排队时版本”。

运行时模型使用完整领域文档；临时隐藏、Solo、锁定、网格线、选择框、视图缩放与平移不影响发布。静帧默认导出“模型实际显示”，另有显式“按编辑器可见对象”模式；后一模式只改变可见输出，仍保留遮罩和合成依赖。静帧也不输出工具辅助线。

### 目标与预设

统一字段为名称、目录、格式预设、输出内容与冲突策略。名称默认项目名/资源名，禁止路径分隔符；跨平台文件名冲突按大小写不敏感规则检测。序列默认 `{project}_{clip}_{frame:04}`，显示首末文件名。目标位置按用途在本机记忆；可携带预设不含用户绝对路径。

内置预设：运行时模型、Cubism 继续编辑、透明 PNG、高清 MP4、透明 ProRes、PNG 序列。用户可保存格式配置预设，修改后显示“自定义”。“再次导出”使用上次成功配置与最新内容重新预检；出现新损失、范围变化、目标冲突或缺失依赖时打开窗口，否则直接执行并通知。

单文件冲突提供“替换 / 保留两份 / 取消”。多文件输出默认创建独立目录，展示文件树；禁止直接覆盖包含无关文件的目录。再次导出仅可替换本工具管理的同一产物集，源项目和被引用资源目录不可作为替换目标。

### 预检与损失报告

| 级别 | 示例 | 对主按钮的影响 |
| --- | --- | --- |
| 阻止 | 缺纹理、无效 ID、尺寸越界、不兼容目标版本 | 禁用，列出具体修复动作 |
| 需决定的转换损失 | CAN3 时间量化、丢弃无法表示的 physics 数据 | 默认严格拒绝；处理完或确认本次具体损失后才能继续 |
| 提醒 | 资源较大、未执行目标运行时校验、可选音频被跳过 | 允许，摘要可展开 |
| 信息 | 使用哪个编码器、生成多少文件、源信息不携带 | 允许 |

列表包含对象/资源、原因、影响和操作。可定位编辑对象、替换文件、提高目标版本或取消相应输出。没有实际转换器的“自动修复”不提供。允许损失的确认绑定文档版本、选项和诊断指纹；更换内容后失效。保存的预设不永久授权丢弃新出现的数据。

执行前固定候选产物与报告，发布的就是已预检字节，不在发布时重读源文件。报告在任务详情永久可查，可导出文本/JSON；模型包和关联项目附带 `export-report.json`，普通 PNG/JPEG 不默认生成旁边的报告文件。

## 模型与可编辑项目输出配置

### Live2D 运行时模型包

默认输出完整文件夹，包含模型入口、MOC3、所有用到的 PNG、已选择的动作/表情/设置及必要附件。model3 是依赖清单，独立导出它不会自动成为完整模型；清单字段与相对路径遵循[官方 model3 schema](https://github.com/Live2D/CubismSpecs/blob/master/FileFormats/model3.json.md)。

| 配置 | 默认 | 约束与说明 |
| --- | --- | --- |
| 模型名称 | 项目名称 | 用于输出文件名和清单 |
| MOC3 目标 | 自动选择最低可表示版本 | 当前编码器目标为 5.0 / 5.3；不是任意 Cubism 版本下拉列表 |
| 动作/表情 | 全选 | 可选择子集，同时重写清单引用和动作分组 |
| Physics/Pose/CDI/UserData | 有则包含 | 未包含依赖会影响外观/交互时预检说明 |
| 声音 | 包含已引用文件 | 缺失时可选择移除对应声音引用 |
| 纹理 | 保留现有图像尺寸与区域布局 | A 不提供未实现的重新打包选项 |
| 校验 | 结构及资源必做；运行时可用时做 | 结构通过不能写成“已验证第三方应用兼容” |
| 打包 | 文件夹 | ZIP 封装为 B；内容一致 |

包含 Offscreen/扩展混合等需 5.3 的特性而强制 5.0 时阻止，推荐提高版本；不提供静默删除效果的降级。将纹理重新打包、最大页尺寸 2048/4096/8192、缩放 25/50/100%、页边距默认 2px、边缘扩展默认 2px、禁止旋转作为 B 的独立“优化纹理”步骤，须同时更新 UV 并展示页数/显存/外观差异；上限以设备和目标格式限制的较小者为准。

现有包构建使用自动编码，显式版本与资源选择需贯穿 SDK/项目导出计划，不在 UI 临时改写最终 JSON。运行时校验结果区分“通过 / 不可用 / 未执行”，与 model3 loader、动画、渲染校验分别记录。

裸 MOC3 默认保留纹理槽布局，展示槽位清单并提供“改为完整模型包”；UI 名称为“仅模型二进制”。高级“仅 model3 清单”要求选择已有目标包并核验引用，不输出悬空清单。

### Cubism CMO3 与 CAN3

默认选择“模型与动画”，统一基础文件名，输出同目录 CMO3/CAN3 和报告。CMO3 可单独输出；CAN3 单独输出仅用于已经有配套 CMO3 的工作流，需要验证源身份与参数/Part 对应关系，单纯找到同名文件不算匹配。

| 配置 | 默认与规则 |
| --- | --- |
| 内容 | 模型与全部动作；有动作时不默认只导 CMO3 |
| 名称 | 项目名；动画场景名来自动作资源名 |
| 目标 | 当前实现的 Cubism 5.3 schema；不承诺所有后续 Editor 版本验收通过 |
| 动作选择 | 全部；B 支持子集快照过滤，不修改源文档 |
| 时间 | 保留每个动作 FPS；CAN3 整帧量化必须列出偏移及冲突 |
| 损失策略 | 严格拒绝；显示具体损失后可“接受这些差异并导出” |
| 配套运行时资源 | 默认关闭；可另外生成完整运行时子目录，不能声称 CAN3 已包含表情/pose |

明确列出：原绘画历史/原 PSD 不可恢复、Kasane 特有编辑手柄等不携带、无法表示的模型特性与物理配置、独立运行时设置遗漏。CAN3 包括时间取整、关键帧或事件碰撞、反向阶梯边界差异、无法映射的效果轨道；允许损失时采用的“保留首个/最后一个”必须展示实际编码器规则，不能仅写“可能略有差异”。

CAFF 混淆 key 不属于用户配置，也不能称为加密。固定编码参数保证可复现。格式支持与实际 Cubism 打开、编辑、保存验收分开记录。

### 原生项目打包

“另存为”改变当前项目保存位置；“导出项目包”生成独立副本且当前文档路径不变。包默认包含所有文档资产（含未使用但有意保留的原图）、动画、设置和已收集附件；“仅使用中资源”为高级选项，先列出将被排除的资源。撤销历史、缓存、预览截图默认不包含；来源路径只记录可携带的相对提示，丢失来源不影响主项目打开。

包内只有一个 `.kasane` 根目录，ZIP 写入相对路径。导出后执行依赖闭合与摘要校验。音频等外部附件必须收集或被明确排除并删除悬空引用。完整原生数据的持久化必须有 round-trip 测试，不能把进程内 undo 历史误当项目内容。

| 输出 | 基本配置 | 高级配置及限制 |
| --- | --- | --- |
| motion3 | 当前/选中/全部动作；名称；完整时长 | A 原样时间、曲线、loop、fade、事件；B 增加区间裁剪、时间归零、烘焙和采样 |

| cdi3 | 名称、分组和可表示元数据 | 默认全部；只输出所选元数据需依赖检查 |

## 静态图像与取景

### 取景是独立的导出状态

无边界模型空间不直接对应像素画布。新建 `ExportFraming` 保存导出矩形、背景与输出尺寸；不改 `ModelSpace`、不改变模型原点，也不复用当前 viewport 的屏幕尺寸。

| 取景模式 | 默认与使用场景 |
| --- | --- |
| 内容包围盒 | 静帧默认，按选定姿态的有效可见输出求值，加 5% 留白 |
| 固定矩形 | 用户输入中心 X/Y、宽/高或在预览中拖动；适合稳定构图 |
| 原稿范围 | 有 source_canvas 时可选，明确可能裁掉模型/动画 |
| 动画全程范围 | 动画默认建议；按最终采样规则顺序模拟后求并集并锁定 |
| 使用当前视图范围 | 显式从 viewport 拍下矩形；之后独立，不跟随缩放变化 |

运行时 MOC3/CMO3 的格式矩形与图片取景分开：现有 SDK 根据默认姿态几何（包含隐藏 mesh）生成边界，按 10% 或每边至少 50px 留白且最小 256px；它不保证覆盖动画全程。不在 A 增加 SDK 不支持的格式矩形编辑器。渲染输出不受这套格式边界裁切。

动画全程范围只保证所选离散采样帧的边界，不能宣称证明连续时间全包围；超采样/运动模糊开启时覆盖其所有子采样时刻。空内容提示改用固定矩形或取消；不产生 0×0 输出。裁切始终画可见边界并统计越界帧。

### 图像配置

| 配置 | 默认 | 有效规则 |
| --- | --- | --- |
| 姿态来源 | 当前上下文：建模参数或动画播放头 | 显示动作名和时刻；也可选模型默认姿态 |
| 尺寸 | 按取景尺寸 1×，等比锁定 | 正整数；长边 1–16384 的设计上限，实际受设备/编码器及内存预算限制 |
| 缩放 | 1×，快捷 0.5×/2×/4× | 与宽高联动，只保留一个有效尺寸来源 |
| 背景 | 支持 Alpha 的格式默认透明 | 棋盘格仅预览；不透明格式默认白色，可选纯色 |
| 质量 | 标准；可选 2× 超采样后缩小 | 先验算工作缓冲大小；不能仅验证最终尺寸 |
| 色彩 | sRGB、8 位 | 明确颜色转换和标记；不把 8 位升格伪称 HDR |
| PNG | RGBA，压缩速度“均衡” | 无有损“画质”；不透明可用 RGB |
| JPEG | 质量 90，白色背景 | 质量 1–100；切换时提示透明区域将合成背景 |
| WebP | 默认无损 RGBA | 有损时质量 1–100，默认 90；Alpha 单独正确编码 |
| 输出 Alpha | 文件使用正确的直通 Alpha 表示 | 内部预乘缓冲转换后编码，校验半透明边缘 |

预览提供适应/100%、透明/背景切换、输出区域拖动；质量预览与最终渲染使用同一配置。估算文件大小只标“估算”，尺寸/帧数是精确值。锁定比例时单边变更重算另一边；解锁仅改变画布矩形，默认不拉伸模型。

### 分层 PSD

内容选“模型默认姿态 / 当前姿态”，默认当前姿态；ArtMesh 作为栅格层，可按 Part 生成组，默认保留名称、绘制顺序与隐藏状态。导出 PSD v1、8 位 RGB，每边不超过 30000，另受内存及文件结构限制。

提供“保留独立网格层”和“按合成组烘焙外观”。后者只有实现等价合成后才开放；无法同时满足外观与独立图层时默认阻止并列出受影响组，让用户决定改为扁平 PNG 或接受明确损失。预览对比整体渲染和图层合成结果。此输出是姿态栅格化，参数、变形器、动画和原始 PSD 文本/矢量/绘画历史均不携带。

## 动画成品输出配置

### 共同时间与求值规则

| 配置 | 默认与边界 |
| --- | --- |
| 内容 | 当前动作；可多选，每个动作独立产物 |
| 范围 | 完整动作；也可工作区间/自定义，起点含、终点不含 |
| FPS | 源动作 FPS；快捷 24/25/30/50/60，支持有理数 24000/1001 等 |
| 帧数 | `N = ceil((end-start) × fps)`，N 必须大于 0 |
| 采样点 | `tᵢ = start + i / fps`，i 为 0 到 N−1；显示编码时长 N/fps |
| 循环 | 沿用动作；循环成品不额外添加重复终帧 |
| 效果 | 默认最终播放效果；列出物理、pose、表情和自动效果的启用状态 |
| 物理初态 | 默认从动作 0 时刻初始化后推进到范围起点；不继承随机播放历史 |
| 预热 | 默认额外 0 秒；可显式输入静止预热时长，报告该值 |
| 音频 | 有参考音轨时默认包含，界面标明实际输出音轨；不支持音频的格式明确显示不包含 |
| 取景 | 固定矩形；默认可分析全程范围，分析完成后锁定，不逐帧自动 Fit |

物理固定步长与输出 FPS 分离，参数驱动按子步求值，不能按“上一张导出帧”随意推进。自动随机效果保存随机种子。循环与预热如导致首尾不连续，展示首尾对比，用户决定修改范围/效果；不偷偷添加过渡帧。

裁剪区间包含 fade 时保留最终求值含义；“原始曲线预览”与“最终播放效果”有明确标签，导出默认后者。渲染顺序固定、音频重采样与起点相同、编码时间戳单调。队列/预览/取消不得改变编辑器播放头和参数。

### 各格式配置

| 格式 | 特有配置与默认值 | 限制和依赖行为 |
| --- | --- | --- |
| PNG 序列 | RGBA、4 位起始编号 0000、均衡无损压缩 | 位数不足自动扩展；同一个动作共用固定画布 |
| WebP 序列 | 无损，支持有损质量 90 | 每帧独立文件，不等同动画 WebP |
| 精灵图 | 最大页 4096²、帧间隔 2px、边缘扩展 2px、禁止旋转、允许多页 | 默认裁透明边并记录原尺寸/偏移；pivot 用统一画布坐标；不能裁出逐帧抖动 |
| GIF | 15 FPS、256 色、全局调色板、抖动开启、无限循环 | 仅单一透明索引；Alpha 默认阈值 50% 并预览损失，或合成背景；时间按可表示间隔量化并累计补偿 |
| 动画 WebP | 源 FPS、无损、透明、loop 继承动作 | 毫秒帧时长需累计补偿；有限循环与目标字段语义对应 |
| APNG | 源 FPS、RGBA、无损、loop 继承动作 | 帧延迟分子/分母须在格式范围内，必要量化并报告 |
| MP4 H.264 | 高质量预设、原尺寸或等比适配 1920×1080、AAC 48 kHz 192 kbps | 不提供透明开关；偶数尺寸约束通过补边并预览，不静默拉伸 |
| MP4 HEVC | 高质量、无透明 | 宿主编码器可用才出现；质量模式与自定义码率互斥 |
| MOV ProRes 422 | 标准质量、无透明、PCM 48 kHz | 大文件估算；编码器可用才出现 |
| MOV ProRes 4444 | Alpha 开启、PCM 48 kHz | 透明工作流默认；需要实测带 Alpha 编码成功 |
| MOV HEVC Alpha，C | Alpha 开启、质量预设 | 独立能力检测，不从普通 HEVC 支持推断 |
| WebM VP9，C | 默认高质量、可选 Alpha、Opus 音频 | 本机构建具备编码器且通过透明通道往返验收才开放 |

视频高级项仅提供编码器实际支持的 profile、码率、关键帧间隔；默认由预设决定。不把文件容器当编码器选择。H.264/HEVC 在 SDR 路径按 BT.709 生成并标记色彩，避免直接把 sRGB 像素误标为视频色彩；透明输出保留经验证的 Alpha 语义。Apple 提供独立的 [HEVC with Alpha 编码类型](https://developer.apple.com/documentation/avfoundation/avvideocodectype/hevcwithalpha)，运行时仍需检测实际可用性。

GIF/动态图片的目标 FPS 不能精确表示时，显示实际帧时长与总时长偏差；不只修改 UI 的 FPS 标签。无动作时动态输出禁用并给“新建动作”入口；长度为零不能生成空视频，静帧导出仍可用。

## 扩展格式的配置契约

C 格式仍需完整定义行为，但不挤入首版菜单。实施前增加格式检测和能力声明；只有这张表中的必要管线已完成，才可启用相应配置。

| 格式或能力 | 导入配置 | 导出配置与启用条件 |
| --- | --- | --- |
| TIFF | 选择页，默认第一页；保留方向与 ICC；高位深转 8 位时显示量化差异 | 位深 8/16 位，默认无损压缩；Alpha 和 ICC 显式保留。16 位仅在渲染到编码全链路具备有效精度时开放 |
| BMP/TGA | 像素尺寸、方向和 Alpha 检测；RGB 与 RGBA 按实际解码识别 | 本方案仅导入，不提供导出入口 |
| SVG | 输出像素尺寸、比例锁定、背景默认透明；字体缺失先处理；外链必须收集或移除 | 本方案仅栅格导入，不输出可编辑矢量模型 |
| 高位深图像 | 颜色空间转换、曝光/色调映射；将裁掉的范围可预览 | EXR 默认半精度 RGBA、线性颜色、无损压缩；导出明确颜色空间与 Alpha 表示，不把 sRGB 编码值写成线性值 |
| GIF/WebP/APNG 导入 | “选单帧”或“参考动画”；保留每帧时长、循环及处置规则；选帧模式显示时间/帧号 | 输出见动画成品表；不把不同帧大小直接当不同的画布 |
| 编号图像序列 | 自动识别编号但必须确认；FPS 默认项目值或 30，无参考值时明确显示；缺帧默认阻止，可选择保持上一帧或透明帧 | 序列输出见 B；不同尺寸默认固定画布居中，先预览，不逐帧拉伸 |
| 参考视频 | 选择视频/音频轨、裁剪区间、原尺寸或代理预览；变帧率按原时间戳求值 | MP4/MOV/WebM 输出见动画表；代理仅影响预览，不能被误当高质量导出源 |
| CSV 参数定义 | UTF-8；ID/name/min/max/default 列；重复 ID 默认阻止；新增或更新必须预览 | 全部/选中参数；默认带表头、点号小数、标准 CSV 转义；不夹带 UI 私有索引 |
| CSV/JSON 曲线 | 区分关键帧 schema 与采样 schema；目标 ID、时间单位、插值和缺失值策略显式指定 | 选中/全部动作，秒默认；采样值模式需 FPS 与范围；关键帧模式保留曲线句柄；JSON 带 schema/version |
| Kasane 项目合并 | 目标 Part、整体位移；模型/参数/runtime ID 映射；默认所有导入对象使用新内部身份 | 只在依赖闭合后作为一笔可撤销操作；共享同名参数必须显式确认，不能默认拼接不同模型的绑定 |
| CMO3/CAN3 导入 | 保留可表示的模型/动画；外部图片和模型定位；时序、参数 ID、Part 身份与结构映射 | 不提供“原样往返”承诺；将不支持的对象列为阻止或具体转换损失，允许用户只导入可独立成立的内容 |

格式支持页按“打开 / 导入 / 导出”三列展示实际能力，列出扩展名、检测到的编码器、Alpha、颜色/位深和当前限制。用户可以搜索后缀；格式不可用时直接说明原因，例如“此版本尚无 CAN3 导入解析器”或“本机不可用 ProRes 编码器”。不要用一个总体勾号混淆格式的两个方向。

## 长任务与失败恢复

点击“导出”后关闭配置窗口并打开任务浮层：名称、格式、阶段、已完成/总帧、预计剩余时间、取消。底层阶段为“准备资源 → 分析范围 → 渲染 → 编码 → 校验 → 写入”。不能估时的阶段显示不确定进度；不伪造百分比。GPU 渲染任务默认一次一个，与交互渲染协调，不复用会丢弃中间帧的 latest-only 预览队列。

任务状态和结果属于任务，不属于当前标签。切换文档、关掉已提交任务的来源文档仍可完成；应用退出且任务未完成时提供“等待完成 / 取消任务并退出 / 返回”。A/B 不承诺重启后续跑视频；重启只恢复任务记录与残留 staging 清理提示。

取消在安全阶段生效，原有输出保持完整。单文件同目录临时写入后替换；多文件先 staging 并校验，再带回滚发布。目录 backup/rename 不是跨文件绝对崩溃原子操作，需要可恢复的提交记录；启动时恢复旧产物或完整新产物，不能把半个包显示成功。写入后目录同步失败归为“已写入，有持久化提醒”，不冒充完全未写入导致重复覆盖。

失败页保留配置，提供“重试”“更换目标”“查看详情”。错误必须具体，如“磁盘空间不足，已完成 92/180 帧”“纹理槽 2 未指定文件”“当前模型使用 Offscreen，需要目标 5.3”。渲染失败不保留一个可被误认成完整输出的截断视频。序列只有在用户显式选择“保留已完成帧”时作为不完整任务保留。

批量动作一项失败不删除其他已完成项目，每项独立提交；批量总体显示“完成 4，失败 1”。单个运行时包内缺一个必需文件则整体失败，不能部分发布。

## 交互细节与无障碍

主按钮文本随内容明确为“导入 24 个图层”“导出模型包”“导出 180 帧”；执行前显示目录和文件数量。用户无需理解编码器内部结构才能完成默认输出。涉及质量与速度的选项用“标准 / 高质量”，高级区再显示具体参数。

键盘可以完成全部路径：Tab 按文件、预览控制、配置、底部动作顺序；Enter 在可执行时提交，输入法组合状态不触发；Escape 关闭配置或请求取消任务，遇到覆盖/损失决定不默认选破坏性选项。错误使用文本、图标及关联字段，不仅依赖颜色；VoiceOver 读出格式、输出大小和阻止原因。

中文和英文同一信息架构，保留 `.motion3.json` 等真实扩展名。长路径中间省略但可复制完整路径，错误可复制且不把本机绝对路径默认写入分享包。状态消息不不断抢焦点，批量进度合并播报。

## 工程落点

### 模块与数据契约

新增 `editor-core::transfer` 负责格式注册、配置校验、导入/导出计划、诊断和任务状态；`editor::transfer` 负责 GPUI 窗口、原生路径选择、进度与命令接入；`editor-render` 提供离屏渲染，媒体编码放在独立适配器。文件解析、模型转换和资源发布继续归 SDK/project 层。

建议核心类型：

```rust
FormatDescriptor { id, direction, extensions, probe, capability }
ImportPlan { sources, target, mappings, options, diagnostics, source_fingerprints }
ExportRequest { document_id, format, typed_options, destination }
ExportSnapshot { document_version, document, resources, evaluation, framing }
PreparedExport { snapshot_id, files_or_frame_plan, diagnostics, validation }
TransferDiagnostic { code, severity, object, source, effect, resolution }
TransferJob { id, plan_id, state, progress, cancellation, result }
```

这些是职责草图，不是可以直接编译的 Rust 定义。配置按格式使用 enum/struct 表达互斥和依赖，不用巨大的字符串 map；媒体容器/codec/Alpha 用合法组合类型校验。每个注册器提供检测、检查、默认值、计划、执行和实际能力报告。未知格式不依赖异常路径猜测。

导入目标捕获 DocumentId、编辑上下文 token 与内容版本。预检时用户切换标签不改变目标；目标已关闭或修改导致映射过时，提交前重新核验。导出绑定快照与任务 ID，不依赖活跃 viewport。已有 `SceneSnapshot.runtime_frame` 与 `viewport_frame` 的区别必须保留；运行时帧还要应用模型 opacity 等最终求值结果，不能只换一个字段就跳过动画效果。

`AuthoringSnapshot` 的文档克隆并不自动保证所有外部资源字节被固定。新增资源解析快照包含尚未保存 PSD 像素、附件、纹理、哈希和必要编码结果，避免仅有 `asset_root` 的路径方案漏掉内存资源。外部文件变化时重新准备，发布不再重新打开它们。

### 实施顺序与完成标准

| 阶段 | 交付 | 完成标准 |
| --- | --- | --- |
| A1 | 格式注册、统一入口、诊断、model3/PSD 预检、裸 MOC3 纹理配置 | 现有导入有同等或更好体验，取消/失败不破坏文档 |
| A2 | motion/exp/physics/pose/CDI 导入与映射；运行时模型包/单资源导出 | 全部引用可校验，未保存文档可导出，默认严格处理损失 |
| A3 | CMO3/CAN3 关联导出、任务与预设、纹理/附件导出 | 产物与预检一致，目标程序打开及关联验收，发布失败可恢复 |
| B1 | PNG/JPEG/WebP 导入与静帧导出；PSD 重新导入 | 颜色/Alpha/坐标验证，源更新可撤销，保留绑定 |
| B2 | 离线动画、序列/GIF/APNG/WebP/视频/精灵图、音轨 | 可复现、范围稳定、无重复末帧、音画对齐 |
| B3 | PSD 输出、打包、纹理优化、动作烘焙 | 外观差异可解释，打包可独立打开，烘焙无二次效果 |
| C | 可编辑格式导入、其他图像/视频、CSV、高位深 | 每个独立格式完成解析/输出与互操作验收后启用 |

阶段内逐项上线，不要求为了列出全部格式而先造空入口。除文档格式与算法测试外，UI 需覆盖如下真实用户路径。

### 验收场景

1. 拖入带重复贴图路径的模型文件夹，只导入一个模型；可选声音缺失能显式跳过，纹理缺失必须修复。
2. 未保存 PSD 修改网格后直接导出运行时包与 CMO3，含正确的内存纹理；源 PSD 字节不变。
3. PSD 不支持的混合/蒙版逐层报错；无栅格像素的文字层不被静默丢弃。
4. 重新导入仅修改像素，网格/参数/变形器保持；模糊匹配不自动覆盖；一次撤销完整恢复。
5. motion3 小数时间与重复轨道经导入原样保留；CAN3 取整碰撞明确阻止或经确认采用已知规则。
6. 运行时包强制 5.0 遇到需 5.3 的特性正确阻止，Auto 选择正确目标并报告；所有清单引用存在。
7. CMO3/CAN3 双文件关联有效，单独 CAN3 不接受仅同名但 ID 不匹配的模型；实机打开后可编辑并保存。
8. 编辑器临时隐藏、锁定、Solo 不改变默认发布；可见对象图片模式仍正确处理遮罩与 Offscreen。
9. 模型远离原稿画布、原点不居中、动画跨越默认姿态边界时，图片/动画取景正确且不逐帧抖动。
10. 半透明边缘分别合成黑白背景，PNG/WebP/透明视频无黑边；JPEG 与 MP4 背景设置真实生效。
11. 2 秒、30 FPS 区间导出 60 帧，末帧为 59/30 秒；非整数帧时长显示实际编码时长，GIF 延迟有一致累计误差处理。
12. 连续渲染、从区间中段开始、重复执行产生相同固定初态物理结果；不依赖用户之前 seek/播放顺序。
13. 磁盘满、取消、权限失败、源文件变化、目标目录有无关文件、发布中断，均没有假成功或破坏旧产物。
14. 开始导出后切换/关闭来源标签，任务来源不改变；追加导入预检过时不写进新活动文档。
15. ZIP 路径穿越、符号链接、异常压缩比和累计像素超预算在写出或大分配前阻止；损坏输入可取消。
16. 导出包在另一目录打开/播放；SDK 结构通过、目标运行时加载、动画和渲染验证各自真实报告。
17. 所有格式的默认配置、空资源状态、英文/中文、键盘和 VoiceOver 路径可操作；窄窗口不遮主按钮。
