# Cubism 笔刷交互与需求方案

状态：需求与交互方案；带累计权重的笔刷选择已实现，其余功能待实施。创建：2026-11-05。更新：2026-11-08。

为 Zipzi Editor 增加变形、扩展与收缩、Warp 整形三类直接变形笔刷，
以及与 Select、Lasso 并列的笔刷顶点选择工具（下文简称“笔刷选择”），
支持 Mesh 和 Warp。快捷键和操作手感尽量对齐 Cubism，工具面板沿用 Zipzi 风格。
需求讨论与实施进度分别记录；笔刷选择的初版交付范围见第 10 节，当前累计权重规则见第 11 节。

## 2 Cubism 行为基线

### 2.1 四种功能

| 功能 | 手册描述的行为 | 本次适用对象 |
| --- | --- | --- |
| 变形笔刷 | 以涂刷方式直接改变对象形状 | Mesh、Warp |
| 扩展笔刷 | 按住鼠标左键使对象扩展；Shift 加按住使其收缩 | Mesh、Warp |
| Warp 整形笔刷 | 根据贝塞尔手柄位置整理分割点，使形状顺畅并修正局部塌陷 | Warp |
| 笔刷选择 | 涂出具有不同权重的选择区域，再对顶点进行移动、旋转或缩放 | Mesh 顶点、Warp 分割点 |

前三种功能依据 [Cubism 变形笔刷手册](https://docs.live2d.com/zh-CHS/cubism-editor-manual/deform-brush/)。
笔刷选择依据 [如何选择](https://docs.live2d.com/zh-CHS/cubism-editor-manual/how-to-choose/)
与 [如何编辑](https://docs.live2d.com/zh-CHS/cubism-editor-manual/how-to-edit/)。

Warp 整形的参考是贝塞尔手柄定义的形状。简单地对相邻顶点求平均，
不能作为已经对齐 Cubism 整形行为的依据。

### 2.2 参数与快捷操作

| 参数 | 含义 | Cubism 快捷操作 |
| --- | --- | --- |
| 权重 | 控制变形影响强度或选择权重 | 本方案不指定快捷键 |
| 大小 | 控制影响范围 | B 加拖动 |
| 硬度 | 控制中心至边缘的权重衰减 | V 加拖动 |
| 形状 | 圆形、正方形、线形 | 本方案不指定快捷键 |
| 角度 | 调整正方形和线形的方向 | C 加拖动 |
| 权重颜色 | 显示影响强弱或选择状态 | 面板设置 |

参数与快捷操作依据 [工具详细面板](https://docs.live2d.com/en/cubism-editor-manual/detailed-toolpalatte/)。
各类变形笔刷分别记忆设置，见 [笔刷调整](https://docs.live2d.com/zh-CHS/cubism-editor-manual/deform-brush/#)。

建议直接变形笔刷首次交付包含三种笔刷形状与以上参数。
笔刷选择已纳入大小、权重、硬度、三种形状、角度和权重颜色设置。
数值范围、初始值、调节灵敏度、
跨应用重启的设置保存方式，以及笔刷选择与其他工具是否共享部分设置，仍需确定。

据此，Cubism 的完整功能可以概括为“用笔刷涂出带影响强弱的顶点选区，再进行变换”。
它同时具备顶点选择器定位和软权重能力，两者应分别写清。

官方文字没有明确以下细节，需要实机核对，不能作为已确认行为写入 Zipzi：

- 无修饰键落笔是否替换旧选区，空白点击是否清空，以及仅点击不拖动的涂选效果。
- 一笔内重复覆盖、多笔叠加、静止按住及擦除时的权重计算、上限和衰减曲线。
- 选区跨工具、变换、对象、关键形状、文档和重启的保留规则，以及选择历史。
- 旋转与缩放的中心计算；工具内能否直接操作变换框，或具体何时必须切回 Arrow。
- Ctrl 在 macOS 对应的实际修饰键，以及笔触中途切换修饰键是否立即改变操作。
- 屏幕/模型单位、缩放关系、重叠点和层级处理，以及各编辑模式中的支持程度。

## 3 对象选择与作用范围建议

先选对象，再使用笔刷。笔刷只影响已选中且可编辑的 Mesh 或 Warp，允许多对象编辑；
经过未选中对象时不改变它，也不自动切换选择。没有有效对象时提示先选择 Mesh 或 Warp。
对于笔刷选择，这里限制的是可涂选的顶点来源，而不是用已有顶点选区限制新选点；
是否允许在笔刷选择工具内先单击取得对象，另见第 4.4.2 节。

选中 Warp 时修改其分割点，子对象通过变形器自然跟随。笔刷不直接修改子对象数据，
除非最终确定的多选规则明确把子对象列为编辑目标。

父 Warp 与子 Mesh 或子 Warp 同时被选中时，直接同时写入可能造成双重变形。
建议几何编辑只作用于选中层级中最上层的对象，并显示实际作用对象；这一规则尚待用户确认，
也需要核对 Cubism 的处理方式。
涂选本身不写几何，不应直接套用这条过滤规则；父子对象的顶点是否允许同时进入选区，
以及后续变换如何避免双重变形，应分别确定。

以下范围细节仍需确定：

- 已有顶点选择是否进一步限制直接变形笔刷的作用范围。
- 隐藏、锁定、隔离范围外以及部分不可编辑对象混选时，是跳过还是拒绝整笔。
- 对象重叠时，是否影响所有选中对象中落入笔刷范围的点。
- 笔刷选择形成的权重是否也约束后续直接变形笔刷。

## 4 四种工具的交互建议

### 4.1 变形笔刷

按下并拖动时，局部形状跟随笔刷运动；停住时不继续变形。权重控制移动程度，
硬度控制影响由中心向边缘的变化。

落笔时固定受影响顶点，还是随笔刷移动更新受影响顶点，会直接改变推拉手感。
在对照 Cubism 前不选定其中一种实现。重复经过同一区域的累积规则也一并核对。

### 4.2 扩展与收缩笔刷

按住左键持续扩展，Shift 加按住持续收缩，移动时作用区域跟随笔刷。
扩展速度应按实际经过的时间计算，避免相同按住时长因刷新率不同而产生明显不同的结果。

需要核对落笔后按下或松开 Shift 是否立即切换方向，以及圆形、正方形、线形的扩展方向。
收缩靠近中心、极高强度和长时间按住时的稳定性需要单独验收；防折叠或位移限制规则待定。

### 4.3 Warp 整形笔刷

在涂刷区域内，将 Warp 分割点逐步整理到贝塞尔手柄所定义的平滑形状，
权重控制每次整理的程度。仅选中 Mesh 时，工具不可用并显示原因。

整形是否在静止按住时持续生效、是否保持贝塞尔手柄不变，以及已有自动整形策略如何参与，
需要对照 Cubism 并检查 Zipzi 的 Warp 编辑语义后确定。

### 4.4 笔刷选择

#### 4.4.1 已确认的基础需求

笔刷选择是独立的顶点选择工具，功能上与 Select、Lasso 并列：

- Select 通过点选或框选建立选区，Lasso 通过封闭路径建立选区，笔刷选择通过涂刷覆盖建立选区。
- 作用元素为 Mesh 顶点和 Warp 分割点。涂刷经过顶点时改变其选择状态，顶点位置保持不变。
- 选区接入已有顶点选择与变换流程；切回 Select 后，使用现有移动、旋转、缩放操作。
- 笔刷选择与三种直接变形笔刷有明确的工具身份和反馈，不以直接推拉代替涂选。

软权重已确认纳入：普通拖动涂权重，笔刷工具内按 Cmd 拖动已涂选顶点，按各点权重移动。
截图中的六种参数均纳入；数位板压感及新的编辑模式仍不自动扩展到本轮。

#### 4.4.2 操作流程建议

以下是 Zipzi 的交互草案，选区增减包含顶点集合与对应软权重；当前合成规则见第 11 节。
官方对照依据见第 2.3 节。

| 阶段/操作 | 建议行为 | 边界或待定项 |
| --- | --- | --- |
| 取得对象 | 可先用 Select 或层级面板选择 Mesh/Warp，再进入笔刷选择 | Cubism 支持工具内单击对象；Zipzi 是否提供这一入口待定，拖动途中不自动切对象 |
| 进入工具 | 提供独立可激活的“笔刷选择”入口，显示可涂选点、现有选区与笔刷轮廓 | 图标、顺序和默认工具快捷键待定 |
| 按下左键 | 捕获落笔前选区、作用对象和视图，开始选择笔触 | 建议在按下处也进行一次覆盖判定，使单次点按可以选点；与取得对象的点击如何区分待定 |
| 无修饰键拖动 | 落笔时清空旧选区与权重，从本笔重新开始；同一笔内持续累积经过顶点的权重 | 普通空白点击也开始新的空选区；清空只发生在落笔时 |
| 追加涂选 | Shift 落笔保留旧选区与权重，继续累积新覆盖 | 重复覆盖已选点不反选；操作模式在落笔时固定 |
| 擦除涂选 | Alt/Option 按强度降低覆盖处的权重，降至零时移出选区 | Alt 优先于 Shift；Cubism 的 Shift + Ctrl 映射不直接照搬 |
| 松开左键 | 完成本笔，保留得到的选区；几何保持不变 | 无变化时不生成模型历史，也不打开形状编辑事务 |
| 后续变换 | 笔刷工具内 Cmd 拖动已涂选顶点，按权重移动；切回 Select 后也保留软权重 | 在笔刷工具内不把普通拖动解释为几何移动；沿用 Select 的变换框规则 |
| 清空选择 | 提供清空顶点选区的操作；软选择启用时同步清空相应权重 | 与取消对象选择、空白点击、空闲 Esc 的关系需和现有选择契约对齐 |
| 取消笔触 | Esc 恢复落笔前的顶点选区及权重 | 保留本笔之前已经完成的选择，不把取消笔触等同于清空全部选择 |

涂选按笔刷扫过的完整区域判断，快速拖动不能仅命中离散事件位置而漏选中间顶点。
鼠标悬停只预览；在已选顶点或变换框上起笔的输入优先级应保证涂选意图明确。

后续变换还需区分点拖动与变换框：Zipzi 现有规则下，零或一个选点时变换框作用于整对象，
两个及以上选点才使用局部选区框，点拖动与键盘微调仍作用于选点。
笔刷选择是否完全沿用该规则、软权重如何确定局部框的有效点集，实施前需要明确并验收。

建议延续现有选择的可见性、锁定、隔离和可编辑性过滤，提供不可选原因；
经过未选中对象不涂选其顶点。没有有效顶点目标时不回退为整对象涂选。
多个已选对象、相互重叠的点以及父子同选的取点策略仍需确认。
Warp 的细分点与贝塞尔控制点需明确区分；本需求明确覆盖分割点，是否连同贝塞尔锚点参与涂选另行确认，
不把切线手柄默认纳入。

#### 4.4.3 普通选区与软选择权重

普通顶点选区表示每个点“选中/未选中”；软选择在此基础上，为每个选点附带 0～1 的影响权重。
软权重已纳入实现，以下是其共同约束；当前合成、采样和默认强度见第 11 节。

- 每个可选顶点有独立权重，建议归一化为 0～1；0 不参与变换，1 完整参与，中间值部分参与。
- 笔刷权重控制写入强度，硬度控制中心至边缘的衰减；颜色显示已存选区权重。
- 普通落笔清空旧结果并开始新选区；Shift 落笔保留并累积已有权重。同笔来回经过和按 Shift 多笔叠加都可以增加权重；Alt/Option 擦除逐步降低权重。
  这是用户确认的 Zipzi 行为；采用剩余空间累积与距离采样，不声称与 Cubism 的内部曲线完全一致。
- 切回 Select 后，移动、旋转、缩放都应消费权重，不能仅显示渐变、实际仍对所有选中点全量变换。
  零权重点保持不动，满权重点执行完整变换；中间权重的具体插值及旋转/缩放中心需另定。
- Select/Lasso 新建、追加、移除选点时，如何设置新点权重及处理既有权重，需明确互通规则。
  建议普通选择新加入的点取满权重，移除的点取零，未触及点保留原权重；替换选择重建相应状态。
- 笔刷选择权重属于编辑选区，不与参数融合权重、BlendShape 权重、蒙皮权重或直接变形笔刷强度混用。

三种形状、角度、硬度和权重颜色的官方能力见第 2.2、2.3 节。建议软选择版本一并提供，
参数默认值、数值范围、线形的长度/宽度含义和压感范围仍待确认。

#### 4.4.4 选区与权重的生命周期

建议把选区及可选的软权重作为临时编辑状态，与现有顶点选择共同管理：

- 同一编辑对象下，笔刷选择与 Select/Lasso 之间切换、完成一次变换后保留选区，便于连续调整。
  切到其他工具是否保留选区及是否显示权重覆盖另行确定，不能让残留权重静默影响直接变形笔刷。
- 平移或缩放视图不改变顶点归属和权重；变换后权重跟随顶点身份，而非停留在画布上的涂色区域。
- 切换对象、文档、基础/关键形状时，清空还是按上下文保留，需要明确；拓扑变化或对象删除后
  必须清理失效点引用，不能把旧索引权重应用到新顶点。
- Esc、焦点丢失、捕获中断、切工具或文档导致当前笔触取消时，恢复落笔前选择状态。
  已完成笔触的保留规则与进行中笔触的取消规则分别处理。
- 涂选是否有独立选择撤销、几何撤销后恢复哪个选区、是否写入工程及重启恢复，均待确认。
  一笔一次几何撤销适用于直接变形或后续变换，不自动套用到涂选本身。

## 5 面板与画布反馈建议

### 5.1 Zipzi 面板

提供与当前工具对应的设置区域：笔刷选择显示选择参数，直接变形笔刷显示三种功能及其参数。
参数采用 Zipzi 现有控件和布局，
避免额外建立一套与属性面板不一致的交互方式。

圆形不需要角度设置；方形和线形显示角度。没有可用 Warp 时，整形入口显示不可用原因。
笔刷选择保留独立选择工具身份，建议与 Select、Lasso 相邻；三种直接变形笔刷共用另一工具入口。
按钮分组、图标和面板布局待讨论。

快捷键需区分工具切换和按键拖动调参。Cubism 默认为 B 切笔刷选择、B 拖动调大小，
而 Zipzi 当前 Select 使用 V、Lasso 使用 L；V 拖动调硬度可能与切回 Select 争用输入。
建议按当前工具、按键与拖动状态进行明确路由，调参手势不同时涂选或写入几何，
文本输入焦点下不触发画布快捷键。是否采用 B 切笔刷选择及如何处理 V 冲突待确认。

### 5.2 画布反馈

直接变形类工具显示笔刷轮廓，并预览当前位置的影响范围与强弱。
笔刷选择持续显示已选顶点；如果纳入软选择，则显示对应权重，即使鼠标移开或切换到 Select，
也能判断后续变换的作用范围。擦除与追加模式应有可辨认的光标或状态提示。

权重显示需要区分当前笔刷预览与已保存的临时选择，避免用户把两者混淆。
颜色设置、几何遮挡与选择标记之间的显示优先级需在界面验收中检查。

笔刷大小采用屏幕单位还是模型单位、缩放画布时笔刷是否同步缩放、
线形笔刷的长度与宽度含义，先作为 Cubism 对照项，不预设行为。

### 5.3 输入设备

鼠标是基础输入。数位板压感是否纳入首次交付尚未确认；如需要，
应明确压感控制权重、大小或可配置的组合，并确认无压感设备的等效默认行为。

## 6 编辑生命周期建议

- 从按下到松开作为一笔，几何变化合并成一次撤销；没有变化时不产生空历史。
- Esc 取消当前笔触，并恢复落笔前的状态。
- 快速拖动保持连续作用，扩展速度不依赖帧率；具体采样策略以手感验证结果为准。
- 沿用现有形状写入规则，编辑基础形状或当前可编辑关键形状，不由笔刷静默创建关键点。
- 不可编辑时在落笔前说明原因，避免完成动作后才发现没有写入。
- 失去窗口焦点、指针捕获中断、切换工具或文档时，按统一手势生命周期结束或取消，
  具体策略在实现前与现有交互契约对齐。

笔刷选择涂选只修改选择状态，不打开模型事务，不将工程标记为几何已修改；若将来决定保存选区，
还需明确相应的持久化与脏状态规则。选择撤销不应未经讨论就与几何撤销混为一体，
尤其要明确撤销变换后应恢复哪些选区及权重状态，详见第 4.4.4 节。

第 10 节的算法记录描述初版代码，当前累积规则如下。

已确认：面板“权重”表示每次涂刷的强度，反复刷同一区域可以逐渐达到 100%，不是最终权重的上限。

- 顶点保存独立的累计权重；用户进一步明确：不按 Shift 落笔时重新开始，按 Shift 才保留旧结果并继续累积。
- 调整笔刷权重只影响接下来的涂刷，不追改已经涂好的权重。
- 同一笔来回经过和按 Shift 多笔重复涂刷，都应能增加权重；累积不能取决于事件数量或刷新率。
- 硬度控制笔刷中心到边缘的影响衰减；颜色和透明度应反映各处已经累计的实际权重。
- Cmd 拖动消费保存的顶点权重：0% 不移动，100% 完整跟随，中间权重按比例移动；移动不重新涂权重。

用户确认累积语义后，采用以下 Zipzi 实现规则；公式与采样密度属于实现选择，不作为 Cubism 的实机结论。

| 项目 | 当前规则 |
| --- | --- |
| 默认强度 | 面板“权重”默认 20%，范围仍为 0～100%；修改设置只影响后续笔触 |
| 落笔模式 | 无 Shift、无 Alt/Option 时先清空旧选区与权重，再从本笔重新开始；Shift 保留并追加；Alt/Option 保留并擦除，优先于 Shift；模式在落笔时固定，Cmd 拖动和 B 调尺寸不清空权重 |
| 单次点刷 | 落笔处应用一次完整强度；有效影响 `a = 笔刷强度 × 形状/硬度衰减` |
| 累积公式 | 本笔涂刷使用 `w_new = w_old + (1 - w_old) × a`；普通落笔从零开始；20% 强度在中心按 Shift 反复点刷约为 20%、36%、48.8%…… |
| 擦除公式 | Alt/Option 为 `w_new = w_old × (1 - a)`；只降低经过处的已有权重 |
| 连续拖动 | 沿实际移动路径等距采样，间距为笔刷较短半轴的 1/8；采样相位跨事件保留，来回经过可重复累积 |
| 距离归一化 | 移动采样的有效影响为 `1 - (1 - a)^(采样间距 / 笔刷直径)`，避免采样点变密而加速涂满 |
| 停留和松手 | 同一位置的重复事件、静止按住、无位移松手不额外增重；悬停和 Cmd 拖动也不涂权重 |
| 上下限 | 达到 99.99% 时归到 100%；擦除至低于 0.01% 时归零并移出选区；零强度不增加或擦除权重，普通落笔仍按规则清空旧结果 |
| 颜色反馈 | 面与网格插值读取累计权重，显示透明度为颜色自身透明度乘以累计权重；顶点填充也读取累计值 |
| Cmd 拖动 | Mesh 顶点和 Warp 分割点使用保存的累计权重；例如 25% 强度点刷后按 Shift 再点刷一次得到 43.75%，拖动 40px 时该点移动 17.5px |
| Cmd 光标 | 空闲时按住 Cmd 显示张手移动光标并隐藏刷圈，拖动已选顶点时显示握手；松开后恢复笔刷十字光标。静止指针也立即换形；已开始的移动或涂刷手势保持原操作光标，结束后再按当前修饰键切换；窗口失焦取消手势并恢复光标 |
| 取消和历史 | Esc、捕获中断等恢复落笔前的选区与权重；涂刷仍不写几何历史，Cmd 拖动沿用一笔一次几何撤销 |

快速移动会补齐中间采样；每个顶点仅遍历其附近的采样，避免长距离指针跳变导致遍历大量无关位置。
