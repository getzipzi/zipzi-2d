# Physics 属性与受干扰项目复测 — 2026-10-23

新增 12 项 Physics 属性负载，默认 Mesh 从 33 项精简为 11 项，颜色选择器仅保留 2 项。完成 26 个正式进程／24,840 次输入；9 组未观察到编译干扰的配对（18 个进程、21,540 次输入）用于性能聚合。播放与动画画布／数值拖动的 UI draw P95 分别高约 16.6%／16.7%／25.8%，两轮配对同方向；播放的新纹理呈现及两类拖动的窗口呈现仍接近 120 Hz。Physics 输入权重和节点灵活度文本的原生事件 P95 大致持平，UI draw 分别高约 23.9%／20.3%；Physics 只有一轮未受编译干扰的配对，不能据此确认稳定回归。

## 版本与负载调整

基线继续为 Editor `44accd1`／kasane-2d `b86b13b`，当前为 Editor `b4e4abc`／kasane-2d `e27230a`。两版同时应用本次完全相同的 benchmark 文件；没有修改产品实现。Release、`test-support`、未启用 `bench-instrumentation`，二进制和驱动补丁 SHA-256 见 JSON。

- 新增 Physics 12 项：组名、输入权重文本／连续拖动、输出权重文本／拖动、输出缩放、节点长度、节点灵活度文本／拖动、归一化中心、输入反射和 idle。每项 5 次预热＋40 次正式输入，三轮配对。
- Mesh 默认从 33 项缩减到 11 项：name、runtime_id、part、masks、opacity_text、opacity_drag、color_blend、enabled、picker_open_close、picker_hex、idle。颜色选择器只保留开关和 HEX 两项；每项 3＋30，两轮配对。完整旧负载仍可用 `KASANE_BENCH_PROPERTY_SUITE=mesh-full` 显式运行。
- 复测此前受后台编译干扰的参数滑条（30＋360）、动画播放（约 10 秒）、动画画布和数值连续拖动（各 2400 次）。全部两轮，版本顺序逐负载交错：基线→当前、当前→基线；Physics 追加第三轮基线→当前。

Apple M4／16 GiB／macOS 27.0.1／120 Hz CB27U1、同一 Mao runtime 模型，隔离配置，默认 Metal mesh overlay，关闭 HUD。所有构建和定向测试先完成，再运行保存的二进制。每个进程启动前尝试等待连续 3 次快照无活动编译器（最多 30 秒）；运行中每秒记录 rustc／cargo／xcodebuild／clang 和高 CPU 进程。第二轮 Mesh 的若干次运行检测到并行 Cargo 编译，已归档到 interfered-attempts，等待后台编译结束后重新测量。仅当同轮同负载两版均未观察到活动编译器时，才将该配对纳入性能聚合；其余记录完整保留。这并不排除其他调度、帧相位或温度波动。

所有数值为每进程分位数／频率的跨轮中位数，不合并原始样本。时间单位 ms；提交 CPU 为线程 CPU，UI draw 和原生事件为墙钟。没有进行显著性检验；两个仓库同时变化，本报告不隔离某个仓库或函数的贡献。
