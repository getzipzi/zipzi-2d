# Document 面板首期实施记录

实施日期：2026-09-30。设计依据：[Document 面板与参数绑定设计](document-panels-design.md)。

本轮完成独立面板、共享文档上下文、对象与关系浏览、真实绑定预览和 SDK 两轴写入约束。关键形创建、批量写入、结构重挂载与完整行为执行工具不在本轮中提供。

## 面板与导航

14 个工具面板分别注册到 Kit Dock；窗口菜单分别控制显示与隐藏。中央画布保留原有固定模型标签页。默认左侧为部件树、变形树、绘制顺序标签组，右侧为属性、关系标签组，下方为参数、关键形上下排列。其余专用面板按需打开。

View（视图）菜单按缩放、工具、主题、快捷键分组；面板入口与布局重置统一保留在 Window（窗口）菜单，避免重复入口。

布局版本升至 v3，原有 v1/v2 布局首次读取时重置为新布局并保存实测尺寸。隐藏、移动或重新组合面板不清除文档上下文。

`editor-core::ObjectRef` 使用对象类型与标识共同定位；`PanelContext` 分开保存对象选区、参数焦点、活动绑定和检查对象，导航返回保留当前预览值。事件继续捕获 DocumentId，并在执行前检查活动文档、活动绑定与模态状态。

部件树只表达部件归属，包含 Mesh、Deformer 和关联 Offscreen；变形树只表达变形父级。展开箭头与行选择分开，外部选择会展开祖先并滚动定位。未归属、缺失引用和循环使用明确分组与诊断。绘制顺序使用当前求值帧的实际绘制计划、分组归属、绘制顺序与 Offscreen 合成命令。

关系面板提供语义明确的正向和反向引用，间接影响路径按需展开。Glue、BlendShapes、Motions、Expressions、Physics、Pose 和资源各有独立浏览入口，包含未使用纹理、附加文件、共享表与约束。未解析运行时目标保留原始标识并可检查。

## 参数与关键形

参数面板按对象去重统计常规直接绑定、BlendShape 目标和间接影响，分别列出具体绑定与继承路径。点击参数名称保留原对象选区；打开具体绑定才切换对应目标，并显示关键形面板。参数分组和空分组保留入口。

参数行采用名称、滑条、数值输入框的单行布局，绑定计数与范围移至名称提示。数值输入使用 Kit NumberInput，隐藏增减按钮；键盘上下键仍以 0.1 步进。数值显示向零截断至一位小数，实际预览值保留原精度。输入失焦或回车后，有限且在范围内的数值直接应用，其余输入还原；未经编辑的显示值不覆盖实际值。移除逐行 Reset 与 Apply 按钮，Esc 仍取消输入。

关键形面板从活动绑定读取完整轴信息和实际存储点，不再把任意两个参数的汇总关键值相乘。原来的参数联合二维预览实现已删除。

一维、二维点选同步全部绑定轴并保留无关参数值；连续拖动与参数滑条共享全局预览值。已存储关键形与插值位置使用不同标记，关键值点选保留原始精度。存在活动绑定时，参数标记使用该绑定的轴；无活动绑定时，明确标注跨目标汇总标记的含义。

仅预览变化不产生 SDK 历史，也不重建对象关系索引。参数拖动定向刷新画布、关键形与绘制顺序；画布平移继续只更新画布。核心对相同有效值和重复关键形点选保留求值缓存。

## 属性检查

Mesh 与其他对象共用只读字段列表，跟随文档共享的检查对象。名称、启用状态、外观、绘制属性、引用标识、顶点和三角形数量等通过同一布局展示；文档入口覆盖画布、模型设置、命中区域和元数据。

属性面板不保存编辑或草稿状态，不创建输入框、滑条、复选框及应用/取消按钮。点击字段不修改模型，浏览与对象导航不产生历史记录。属性编辑交互留待后续设计；现有 editor-core 与 SDK 编辑命令继续保留。

## SDK 与高维兼容

相邻 `kasane-2d/modules/kasane-sdk/src/edit.rs` 同步修改。常规 Mesh、Scene、Glue 绑定的创建、替换、关键形操作以及复合事务均受两轴限制；提交前还比较完整候选模型，防止其他编辑入口绕过限制。失败事务保留内容、版本、事件和撤销重做历史。两轴可以拥有超过九个关键形。

既有三轴以上绑定采用只读兼容：打开、导入、求值、保存、重新打开以及无关标量编辑保留原始数据；绑定修改、隐式降维和保留目标时删除后重建绑定会被拒绝。删除目标本身仍遵循原 SDK 规则。界面展示轴与关键形数量并标明绑定只读，全局参数预览仍可使用。

`editor-core` 的投影缓存使用独立递增版本，覆盖候选更新、取消、提交、撤销和重做。首次投影在文档加载期间生成；预览拖动复用不可变索引，专用面板不另建可修改的模型副本。

## 自动检查与手动验收

自动回归覆盖共享上下文、跨文档隔离、真实组合与精度、独立绑定不生成假网格、继承路径与计数、特殊内容正反向引用、未解析目标、标量历史与候选取消后的缓存恢复。GPUI headless 回归覆盖独立布局、树选择、隐藏关键形面板后绑定导航、关键形与参数双向同步、模态阻止编辑、只读属性检查与导航、拖动失焦与画布平移通知范围。

SDK 回归覆盖 Mesh、Scene、Glue 第三轴拒绝、两轴大网格，以及旧三轴工程求值和保存重开。运行：

```sh
cargo test --locked --workspace
cargo fmt --all -- --check
cargo test --locked --manifest-path ../kasane-2d/Cargo.toml -p kasane-sdk
cargo fmt --manifest-path ../kasane-2d/Cargo.toml -p kasane-sdk -- --check
```

未进行真实窗口的视觉或拖拽验收，仍需手动检查：

1. 14 个工具面板自由拆分、组合、拖动、缩放、隐藏和重开，退出后恢复布局。
2. 在较小窗口、不同 DPI 和较大工程下检查列表滚动、文本截断与关键形控制区域。
3. 拆开属性/关系、参数/关键形后交叉导航，切换文档和撤销后确认上下文与画布一致。
4. 使用实际 Motion、Physics、Pose、BlendShape、Glue 与缺失资源模型检查专用列表与引用诊断。

后续仍需设计关键形创建与初始化、明确的形状写入工具、相同布局的批量编辑、结构重挂载、Motion 时间轴与播放工具、Physics 调试工具。本轮不会从插值预览隐式生成或覆盖关键形。
