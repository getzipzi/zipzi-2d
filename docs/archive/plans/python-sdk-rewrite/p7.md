## 生成与手写责任

Rust 选定声明/编译注册 → `schema/authoring.json` → 生成值、codec、facade、后端接线和目录/参考；普通便利调用把投影交给手写 Call，正常/恢复共用返回链。特殊传输由生成的 `TRANSPORT_HOOKS` 登记原因与 C01/C07/C08；生命周期请求在 `generate_api.py` 集中登记。领域算法、默认值、身份和历史仍在 SDK/Core；候选、来源、预算、Job 与调度在 Runtime。
