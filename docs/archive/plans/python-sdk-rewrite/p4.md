## Save As 与磁盘历史的实际边界

SDK 的既定规则是：当前内容复制到新工程；同 ID 的旧内容若仍由磁盘历史引用，
其 Undo 路径重定位为原工程中的绝对路径。新工程当前图片独立可读，Undo 的旧
图片仍依赖原文件存在。显式 `ImageLease` 则固定捕获的字节和像素，原文件暂时
不可用或被改写后仍可读。普通新读会检查实际磁盘，不用旧缓存掩盖缺失或损坏。

本轮暂时移开原工程目录验证这些行为，再恢复它并检查 Undo/Redo 的像素、
诊断和历史；该规则与 SDK `save_as_keeps_old_resource_for_same_id_and_new_resource_for_redo`
一致，没有扩展为“另存时复制全部历史文件”的新要求。
