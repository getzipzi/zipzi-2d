# P3A-2：统一值、操作和规划

日期：2026-10-25。状态：**已完成并通过本阶段验收。** 前置 P3A-0/P3A-1 已通过。

## 成果

- 查询统一为根模块的 `Snapshot[T]`、`Batch[T]`，领域纯值不携带重复来源。
  空批次仍有确切 Source；正常调用、原请求恢复和二进制结果使用同一形状。
  `Page`/`PageCursor` 已定义值形状，实际分页继续归 P3A-4。
- 操作构造器归 `meshes/parameters/bindings/resources/scene/modeling`；`ops` 只导出
  `Operation`、`PlannableOperation` 两个静态联合。参数字段值使用 `ParameterPatch`。
- 参数、绑定、采样、事件和引用 DTO 从编译后的 Rust 声明生成，公开模块移除手写字段列表。
  输入集合在构造时拥有化；参数/绑定 Native 转换与采样检查也使用同一声明生成。
  生命周期包装、游标身份校验和 Runtime 领域规则继续由既有手写层负责。
- `session.plan(operation)` / `edit.plan(operation)` 与直接 apply 共用领域操作。
  网格和图片改名支持可选 `expected_name`，SDK 同时检查直接执行和规划的前置条件。
  未给出条件时，规划仍绑定确切 Source；默认标签在复制前执行内存准入。
- `edit.apply(plan)` 与 `apply_many((plan, operation, ...))` 共用候选入口；Plan 最多一个且必须首项。
  来源过期、跨候选、错误顺序及失效句柄不会部分发布；报告关闭后仍可读。
- 删除公开 `RenameIntent`、`ModelingIntent*`、`ApplyPlan`、`apply_plan` 和领域 facade 的平行 plan 入口。
  保留地址规划的 incarnation/context/field epoch 检查；异步规划通过 Session/Edit 接受已注册的建模操作子联合。
- Plan、PlanCost、PlanReport 归根模块；原 plans 模块收为内部实现。
  修复生成 dataclass 的私有标记构造参数泄漏，并让必填字段/默认值遵循 Rust 声明。
- Native 配对为 `zipzi-python2-13`，IPC 为 `zipzi-runtime-p3a-2-1`；当前调用方、类型样例和安装 recipe 已迁移。
