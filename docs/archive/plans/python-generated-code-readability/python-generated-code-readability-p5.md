# Python 生成代码可读性：P5 收尾

2026-10-30。生产生成器只接受版本 2 的规范化类型图，过渡展开适配器已移除；
合成契约的展开仅用于测试中修改嵌套字段。README 补充了生成、分片和重放入口。
离线安装审计递归检查文档链接及锚点。生成 binary adapter 首次调用时缓存跨领域
依赖，避免拆分后的重复导入；离线 `describe` 使用有界内部缓存，同时保留公开
函数的反射行为。

静态统计范围与 P0 相同：总量由 15,028,411 降至 6,432,173 字节；最大 JSON
分片为 167,941 字节、5,518 行，生成代码或领域 reference 最大为 1,459 行。
733 个建模值类和 311 个完整类型投影的领域覆盖率均为 100%；无效原值回写、
重复字段块和重复的继承方法说明均为零。

同机使用 `./tools/dev-python`，分别对基线提交 `0d5692db` 和最终版本交替启动
三个进程；表中是中位数，准备和 native 编译不计入被测调用。编码使用单个网格
重命名操作，每进程七组各一万次，检查输出字节完全相同。以下是本机观测，
不是跨机器性能保证。

| 测量 | 基线 | 最终 |
| --- | ---: | ---: |
| import | 144.2 ms | 151.7 ms |
| 首次 describe | 1.632 ms | 0.482 ms |
| 重复 describe | 0.704 µs | 0.083 µs |
| import/首次查询后的进程峰值 RSS | 46,891,008 B | 40,665,088 B |
| binary 网格命令编码 | 2.340 µs | 2.384 µs |

与 P0 记录相同的单次全进程生成负载：无缓存检查由 3.89 s / 317,390,848 B
变为 2.94 s / 284,164,096 B；预热缓存检查由 0.74 s / 140,804,096 B 变为
0.55 s / 105,218,048 B。两者包含契约导出，不包含首次编译准备。

验证：完整 `test_python2_codegen.py` 31 项（含独立 checkout 的实现改动、字段、
默认值、枚举、操作输入输出、缓存与失败恢复）；`python2` 103 项行为、16 项
恢复及正反例类型检查；`python2-connected` 20 项；契约 crate、schema、类型图、
输出管理测试及无缓存生成检查均通过。

分发门禁从源归档构建纯 wheel、native wheel 和独立宿主，并通过归档直接导出、
重放及 Local/Connected 安装示例。随后为保留公开 `describe` 的函数反射行为将
缓存移入内部，重新生成并构建纯 wheel、重放最终源归档，重新运行 discovery、
类型检查、纯 wheel 审计以及与已有 native wheel 配对的 Local/Connected 示例。
离线审计检查 1,014 个符号、1,900 个 callable 和 2,410 个字段，各类失败为零；
完整逻辑契约摘要与分发报告和安装元数据一致。
