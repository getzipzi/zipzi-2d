# Editor foundation 实施记录

2026-09-28。依据 [目标设计](editor-foundation.md) 完成五个步骤的代码与自动化验证。
原生交互仍有未人工验证项，完整列在文末；实现工作不等待人工验收。

## 架构与交付

| 模块 | 职责与结果 |
| --- | --- |
| SDK / Document | SDK 独占模型、事务、历史和项目发布；Document 管理选区及属性/顶点候选 |
| core / DocumentSession | 独立视口、场景缓存与版本、工具控制器、稳定顶点选区和活动手势 |
| core / Editor | 多文档、运行期 DocumentId/OperationId、路径去重、异步任务归属、关闭/退出、显示版本检查 |
| core / commands + settings | 稳定命令 ID、本地化 key、业务作用域、可用性、重复策略；配置整体验证、版本及原子写入 |
| core / viewport + tools | 源模型与画布局部逻辑坐标、前向/逆向变换；命中、固定拖动基准、OverlaySnapshot |
| editor / EditorView | 平台 Action/KeyBinding、文件对话框、后台执行器、属性控件和菜单 |
| editor / docking + canvas | Kit DockArea/DockSkin、持久布局、独立 CanvasView、实测 bounds/DPI、焦点/指针捕获、辅助图形 |
| editor / preview | 共享 GPUI device/queue；一个执行中请求与一个可替换的最新待执行请求 |
| zipzi-editor-render | 不可变 Metal 输出，消费 core 变换；按内容哈希与尺寸复用纹理，128 MiB 近期缓存 |

沿用三个业务 crate，模块拆分已维持 UI/核心/渲染边界，没有新增插件框架、历史栈或事件总线。

1. 多文档：成功打开/导入新增标签；目录、manifest 与符号链接去重；相同模型 UUID 的不同文件保持独立。
   会话独立保存历史、选区、工具和视口，后台任务携带文档及操作身份。
2. 命令：菜单、工具栏、快捷键共用核心命令和可用性。文本 Undo/Redo 留给 Kit，工作区打开/保存仍可用。
   模态上下文阻断底层动作；仅缩放允许按键自动重复；V 仅在画布上下文生效。
3. Dock：工具面板可移动、分组、拆分、调尺寸、折叠/隐藏；模型始终属于工作区，隐藏面板不会关闭模型。
   中央 CanvasView 不可关闭、无面板标题栏；布局校验阻止把它并入工具标签组或移至边栏。
4. 画布与工具：实测实际区域和 DPI，模型、控制点、线与命中共用变换；中键平移、缩放、重置。
   顶点采用稳定 ID，8 逻辑像素命中半径，按距离再按 ID 决定重合命中，Shift 切换多选。
   一次拖动固定目标和原始坐标，最终 mouse-up 位置提交一次；返回原点/取消不破坏 redo。
   参数绑定、变形器、BlendShape 或 Glue 网格保持可查看并显示不可编辑原因。
5. 保存与性能：保存移交原会话到后台，冻结对应标签，其他文档仍可编辑；失败归还原会话和历史。
   已采集完整 Mao/Shirousagi 的 CPU 与原生 Metal 工作负载，见 [基线](editor-foundation-baseline.md)。

## 配置与键位安装

macOS 默认目录为 `~/Library/Application Support/Zipzi Editor`；可用 `ZIPZI_CONFIG_DIR`
注入其他目录，测试只使用临时目录。键位配置为 `keybindings.json`，修改后重启生效：

```json
{
  "version": 1,
  "data": {
    "bindings": [
      { "command": "file.open", "keys": ["cmd-alt-o"] },
      { "command": "file.save", "keys": [] }
    ]
  }
}
```

省略命令沿用默认；空数组取消绑定。菜单中的快捷键清单展示当前有效键位和配置位置。
恢复默认会写入空覆盖并立即重建最终绑定及原生菜单，不遗留旧覆盖。
未知命令、非法键名、多段键、同作用域冲突或平台/文本保留键冲突使整份配置被拒绝；
优先恢复 `keybindings.last-good.json`，否则采用默认，并在界面提示错误。
`layout.json` 独立保存版本化 Kit 布局；损坏、未知面板、重复 Canvas 等配置回到默认。
两个配置均先写临时文件、sync，再原子 rename，不进入项目文件或历史。
布局变化通过后台串行写入合并，连续变化停止 150 ms 后落盘；退出时刷入最后一份布局，
避免在 Dock 拖动/调尺寸的 UI 回调里执行文件同步。

实现前核对锁定 Kit `5059de47` 与 vendored GPUI：`bind_keys` 为追加，原生菜单优先较早绑定；
因此先通过当前平台 KeyboardMapper 解析、规范化并验证整份配置，再只安装最终绑定。
恢复默认时保留 Kit 原有绑定后重建编辑器绑定。无窗口 Keymap 测试覆盖上下文互斥与旧键移除。
当前 Kit 没有逐面板的拖拽锁：Canvas 隐藏标题栏，并对 LayoutChanged 校验，非法布局回退上一份有效值；
没有修改 Kit 或新增 vendor 补丁。

## 版本与手势协议

每个请求携带 `DocumentId + SceneRevision + ViewportRevision + RequestId`。
模型候选变更递增场景版本，导航/尺寸/DPI 仅递增视口版本；悬停和选区只刷新辅助层。
新帧到达前保留上一组匹配的画面和几何，完成时一并替换；禁止新几何覆盖旧模型。
开始拖动要求显示帧已匹配当前版本，拖动期间不随异步帧重新选择目标。
零尺寸和隐藏窗口暂停提交；后台模型不持续渲染。

Esc、工具/文档/图层切换、保存、关闭、失焦、窗口停用、指针释放丢失或 SDK 更新错误均取消画布候选。
顶点拖动期间不允许缩放；中键导航先取消活动拖动。属性 Enter/blur 仍提交。
保存任务成功或失败返回同一会话，错误工作区拒收不会消费完成结果。

## 首轮实现复审修复

- 保留同一活动文档的已显示画面：重复点击当前标签或保存完成时，不再清空画面后又因场景缓存命中而不提交新帧。
- 保存归还会话时更新视口版本：保存期间的窗口尺寸/DPI 变化和被拒收的渲染结果都会触发重新提交；新帧到达前禁止用旧变换开始编辑。
- 帧接收验证活动文档身份；辅助层和指针输入还验证 UI 实际持有的图像版本，避免返回标签时只有缓存几何而没有对应图像却仍可操作。
- 区分关闭单个文档与退出触发的保存后关闭。取消退出或保存失败会撤销退出附带的延迟关闭，同时保留独立关闭文档的意图。
- 顶点仅选中、未移动时不提交 SDK 位置更新、不失效场景缓存；拖动最后位置不变也不额外求值。
- 属性控件按文档和图层重建，避免同名图层共享文本撤销历史；丢弃旧控件排队到达的事件。
- Dock 布局持久化移至后台，覆盖连续变化合并、退出刷盘与写入错误上报的自动化测试。

本轮新增 7 项回归测试。画布/保存/退出回归与工作区、配置、原生 Metal 测试均已执行；
属性控件的原生文本撤销和焦点切换仍在下面的人工验收范围内。本轮未重新测量端到端性能基线。
