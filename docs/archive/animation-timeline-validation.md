# Animation Timeline 第四阶段验收

日期：2026-10-14。真实导入动作、密集编辑、事务／图像恢复和 SDK 结果一致性通过下述验收。原生窗口合成帧率尚未复测：脚本检测到 Mac 锁屏，未启动原生窗口测量。

## 环境与数据

- Apple M4，10 核 GPU，16 GiB 内存，Mac16,10；macOS 27.0.1（26A434），Metal HUD 关闭。
- Release headless Metal，逻辑窗口 1100 × 740，截图 2200 × 1480。所有时间以墙钟测量。
- 编辑器以 `bf01a3c` 为基线，加本阶段变更；SDK 为 `2e75792`，本阶段未修改 SDK。
- 真实来源为本地 Mao 的 `special_03.motion3.json`：132 条曲线、619 段、751 个关键点。增加一条重复参数轨道及一条缺失参数轨道后，验收版有 134 条轨道、779 个关键点。已有未解析目标一并保留，合计 4 条未解析轨道。
- 压力版用 SDK 原始采样为每条轨道生成 257 个线性关键点，共 34,438 点；保留各轨道的合法尾点范围。这是单独标明的压力数据，不代表原动作已有这些关键点。另导入带未知 vendor 扩展的只读变体。

许可模型缺失时，普通测试显式 `SKIP`；性能脚本设置 `ZIPZI_TIMELINE_REQUIRE_ASSET=1`，缺失模型会失败。原始资源不修改，临时变体与资源副本自动清理，没有将许可数据、截图或原始结果提交到仓库。

## 功能证据

- 真实验收版保留 494 个子帧关键点；名义时长为 f32 的 9.23 秒，最晚关键点为 9.233 秒。导入、编辑取消、Undo、保存与重开均未量化这些时间。
- Bezier 段插入未改值的关键点，以 SDK 采样 513 个位置，前后最大误差为 `4.7683716e-7`。Undo 恢复全部曲线与 UUID。
- 同一参数保留两条具体轨道，编辑预览按 SDK 顺序由后轨覆盖前轨。实际画面拖动选择后轨。未解析通道保留曲线并报告不可编辑；未知扩展变体无法开始候选编辑，保存／重开保留其完整内容与指纹。
- 同时移动两条轨道，其中一条发生精确时间冲突时，候选完整保留原值，无部分修改。
- 实际 GPUI 鼠标事件进行连续 32 次候选更新。每次等待当前候选的 CPU／Metal 身份被接受，资产保持原值；候选画布像素改变。Escape 后画布逐像素恢复，资产和历史不变。
- 另外连续发送 8 次候选更新，不等待完成即取消，再发送过期移动／释放；旧 CPU／GPU 输出不能覆盖恢复画面，过期指针不能重启事务。
- 释放拖动只新增一次历史，Undo 恢复所有关键点身份和曲线。三个导入变体在无操作保存／重开后完整 `MotionClip` 相等。
- 结果预览使用同一 Motion 注册及 Expression 调度，在 0.1137、1.125、9.23、0.25 秒定位。编辑器参数快照、几何以及实际已呈现快照均与独立 SDK `MotionPreview` 一致，涵盖前进和回退。

## 性能测量

滚动和拖动通过 GPUI 原生事件分发。拖动延迟从注入鼠标移动开始，到当前候选的 SDK／Metal 纹理被编辑器接受并完成一次 GPUI draw；不包含截图回读、OS 输入投递或系统合成呈现。定位从 zipzi-editor-core 定位调用开始，使用相同的当前身份检查。测量不能将等待期间保留的旧画面计为新结果。

每个版本滚动 600 次、拖动采样 32 次、逐次定位 32 次，另连续发送 600 个快速定位目标并等待最终身份。两组播放各以 60 Hz 驱动 600 个时钟目标，约 10 秒。

滚动使用全部轨道的总览。拖动、定位和播放使用单通道曲线视图，搜索 `ParamAngleX`，选择其最后一条具体轨道，时间范围为 0–0.1 秒，关闭帧吸附。拖动修改首关键点的数值，时间不变；每次更新仍生成完整 Clip 候选和 SDK 快照。这组数据不能推广为同时显示所有曲线或批移全部关键点的耗时。

| 测量（ms） | 真实动作版 P50 / P95 / 最大 | 34,438 点压力版 P50 / P95 / 最大 |
| --- | --- | --- |
| 滚动事件到 GPUI draw | 3.38 / 4.46 / 11.11 | 6.30 / 7.60 / 19.35 |
| 拖动事件分发及候选更新 | 8.70 / 9.24 / 9.59 | 37.86 / 38.98 / 40.18 |
| 拖动到当前 Metal 画布及 draw | 13.54 / 14.06 / 14.76 | 43.02 / 45.05 / 45.34 |
| 定位到当前 Metal 画布及 draw | 6.31 / 6.74 / 6.91 | 6.58 / 7.08 / 9.91 |

600 个快速定位的分发加最终排空分别为 843.3 / 871.5 ms，最终目标均为 2.5691752 秒，实际呈现身份准确匹配。处理中取消到恢复当前 Metal 画布分别为 18.6 / 31.9 ms；随后截图证明像素恢复。

两组各观察到 599 次不同时间的画面，首个时钟目标 0 与基线相同；轮内目标与画面时间最大差约一个 60 Hz tick。静态曲线层均为 **0 次重建、0 次重绘**，滚动全程保留同一份行树 Arc。该 headless 驱动结果不能作为原生窗口帧率或显示器呈现节奏的证据。

复用手势开始时的候选／投影前，同一压力数据的拖动 P50 / P95 / 最大为 57.10 / 59.69 / 61.05 ms；复用后为 43.02 / 45.05 / 45.34 ms。前后各 32 次拖动，顺序运行，无并行测试负载。压力版 P95 下降约 25%，仍高于 16.67 ms；这轮优化没有声称任意密度均可 60 Hz 编辑。

顺便修复了附近关键点按最后绘制顺序命中的问题，改用最近真实点；同位置点继续要求消歧。深度缩放时标尺增加必要的小数位，子帧与子秒刻度不再重复标签。原生窗口播放 benchmark 显式选择结果预览，避免测到默认编辑预览而误标完整运行管线。

## 复现与输出

```sh
env -u ZIPZI_DEV_SESSION_DIR cargo test --locked -p zipzi-editor --test timeline_acceptance
./scripts/timeline-benchmark.sh target/timeline-new-run 600

# 需要 Mac 已解锁，窗口可见且激活：
env -u ZIPZI_DEV_SESSION_DIR ./scripts/animation-window-benchmark.sh \
  models/local/mao/runtime/mao_pro.model3.json target/timeline-native-new-run 600
```

`ZIPZI_TIMELINE_MODEL` 可指定本地 model3 来源；本验收需要其中存在 Bezier、子帧及合法尾点的动作。`ZIPZI_TIMELINE_OUTPUT` 和 `ZIPZI_TIMELINE_SAMPLES` 控制直接运行测试时的输出目录和采样数。

本次结果位于忽略的 `target/timeline-final-release/`，包含环境、构建／运行日志、`results.json` 和 Natural／Dense 的候选前、候选中、取消后三组截图。优化前后对照为 `target/timeline-before-candidate-cache/` 与 `target/timeline-candidate-cache/`。`target/timeline-native-result/` 没有有效合成测量；锁屏退出原因保留于本次运行日志 `/tmp/timeline4-native.log`。
