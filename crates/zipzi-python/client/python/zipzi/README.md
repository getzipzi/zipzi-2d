# Zipzi Python SDK

The [workflow guide](docs/guide.md) covers v4 host selection, sourced queries,
Drafts, project I/O and recovery. The installed [recipe](docs/recipes.py) shows
a complete Local authoring workflow.

Generated types are available offline in `zipzi.values`. The package requires
the matching optional native backend for Local sessions. Connected sessions use
a private endpoint on a running v4 host.
